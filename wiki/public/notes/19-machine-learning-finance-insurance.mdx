## <a id="1"><b>1 Basic Notions of Statistical Learning</b></a>

<b>Definition $\sigma$-algebra</b>

_Firstly,_ we remember that a $\sigma$-algebra $\mathcal{F}$ is a non-empty collection of subsets of $\Omega$ that contains $\Omega$ itself and is closed under complementation and countable unions, i.e. it satisfies the following:
- contains the whole space $\Omega \in \mathcal{F}$
- closed under complementation: $\text{If } A \in \mathcal{F}, \text{ then } A^c = \Omega \setminus A \in \mathcal{F}$
- it is closed under countable unions: $\text{If } A_1, A_2, A_3, \dots \in \mathcal{F}, \text{ then } \bigcup_{n=1}^{\infty} A_n \in \mathcal{F}$

From this definition, we provide some examples:
- <b>Trivial $\sigma$-algebra</b>: $\mathcal{F} = \{\emptyset, \Omega\}$ _(the smallest $\sigma$-algebra)_
- <b>Power set</b>: $\mathcal{F} = \mathcal{P}(\Omega)$ _(collection of all subsets of $\Omega$, the largest possible $\sigma$-algebra)_
- <b>Borel $\sigma$-algebra</b> _(smallest $\sigma$-algebra generated by all open sets in $\mathbb{R}$, it is the essential foundation for measure theory and real analysis)_

_Intuition: in $\mathbb{R}$, consider all the intervals $(a,b)$ and perform all three actions that define the $\sigma$-algebra (complements, countable unions, countable intersections, where the last one nicely derives from the definition of $\sigma$-algebra): the resulting set is the Borel $\sigma$-algebra $\mathcal{B}(\mathbb{R})$ and represents every subset of $\mathbb{R}$ that can be obtained using standard mathematical operations.)_

We also recall that a function $f: X \to Y$ is <b>Borel measurable</b> if:

$$
f^{-1}(B) = \{x \in X : f(x) \in B\} \in \mathcal{B}(X) \quad \text{for every } B \in \mathcal{B}(Y)
$$
_Intuition: if the preimage of every Borel set in $Y$ is a Borel set in $X$._

---

<b>The prediction problem</b>
<br/>
Consider the following:
- a probability space $(\Omega, \mathcal{F}, \mathbb{P})$, i.e.:
    - a non-empty set $\Omega$, the _sample space_
    - $\mathcal{F}$, a $\sigma$-algebra of subsets of $\Omega$,
    - a probability measure $\mathbb{P} : \mathcal{F} \to [0,1]$
- a feature space $\mathcal{X} \subseteq \mathbb{R}^d$ with Borel $\sigma$-algebra $\mathbb{B}_{\mathcal{X}}$ _(example: $\mathcal{X} = \mathbb{R}^m \times \{1,2,\ldots,n\} \times \mathbb{N}$)_
- a closed or open target space $\mathcal{Y} \subseteq \mathbb{R}^k$ with Borel $\sigma$-algebra $\mathbb{B}_{\mathcal{Y}}$ _(example: $\mathcal{Y} = \mathbb{R}$)_
- some random elements $X : \Omega \to \mathcal{X}$ _(inputs)_, $Y : \Omega \to \mathcal{Y}$ _(outputs)_




We then consider $\rho_X, \rho_Y, \rho$ the distributions of $X, Y, (X,Y)$ and $\rho_{Y \mid X}$, that is the <b>regular conditional distribution</b> of $Y$ given $X$, that is:
- $\forall x \in \mathcal{X}: \rho_{Y \mid X}(\cdot \mid x)$ is a probability measure on $\mathcal{Y}$
- $\forall B \in \mathbb{B}_{\mathcal{Y}}$, $x \mapsto \rho_{Y \mid X}(B \mid x)$ is $\mathbb{B}_{\mathcal{X}}$-measurable
- $\forall B \in \mathbb{B}_{\mathcal{Y}}$, $\mathbb{E}[\mathbf{1}_B(Y) \mid X] = \rho_{Y \mid X}(B \mid X)$ $\mathbb{P}$-almost surely.

Then, it follows, for all $\rho$-integrable $h: \mathcal{X} \times \mathcal{Y} \to \mathbb{R}$, we have the <b>disintegration of $\rho$</b>:
$$
\int_{\mathcal{X} \times \mathcal{Y}} h(x, y) \, \rho(dx, dy) = \int_{\mathcal{X}}\int_{\mathcal{Y}} h(x, y) \, \rho_{Y \mid X}(dy \mid x) \, \rho_X(dx)
$$


We now go back to the prediction problem: we want to find a measurable function $f: \mathcal{X} \to \mathcal{Y}$ s.t. $f(X) \approx Y$, i.e. a function that allows us to minimize the <b>expected loss</b> (also called <b>risk</b>), defined as:

$$
\mathbb{E}[\ell(f(X), Y)] = \int_{\mathcal{X} \times \mathcal{Y}} \ell(f(x), y) \, \rho(dx, dy)
$$

for a measurable loss function $\ell: \mathcal{Y} \times \mathcal{Y} \to \mathbb{R}_+$.

Then, _in machine learning_, it is common to solve the <b>empirical loss minimization problem</b>!

---

<b> Regression Functions and Irreducible Error </b>

<b>Lemma (theoretically best predictor with respect to a given loss function $\ell: \mathcal{Y} \times \mathcal{Y} \to \mathbb{R}_+$)</b>

Let $\bar f: \mathcal{X} \to \mathcal{Y}$ be a measurable function such that, for $\rho_X$-almost every $x \in \mathcal{X}$, $\bar f(x)$ minimizes

$$
w \mapsto \int_{\mathcal{Y}} \ell(w,y)\,\rho_{Y\mid X}(dy\mid x)
\in [0,+\infty].
$$

Then

$$
\mathbb{E}[\ell(\bar f(X),Y)]
\leq
\mathbb{E}[\ell(f(X),Y)]
$$

for every measurable function $f:\mathcal{X}\to\mathcal{Y}$.

Note that $\bar f(x)$ is the _ideal predictor_ we would use if we knew the true conditional distribution of $Y$ given $X=x$. For each $x\in\mathcal X$, if we predict a value $w\in\mathcal Y$, the conditional expected loss is

$$
R_x(w) = \mathbb E[\ell(w,Y)\mid X=x] =
\int_{\mathcal Y} \ell(w,y)\,\rho_{Y\mid X}(dy\mid x).
$$

The function $\bar f$ chooses the prediction that minimizes this conditional risk:

$$
\bar f(x) \in \operatorname*{argmin}_{w\in\mathcal Y} R_x(w).
$$

_From now on_, we suppose these assumptions from the lemma hold and we call:
- $\bar f$ <b>regression function</b> _(or, more generally, the Bayesian-optimal predictor)_
- $\mathbb{E}[\ell(\bar f(X),Y)]$ <b>irreducible error</b> _(even with the exact conditional distribution, randomness in $Y$ given $X$ can prevent perfect prediction)_

---

<b>Example: Square loss </b>

We consider now the following example with $\mathcal{Y} \subseteq \mathbb{R}$, $\ell(w,y) = (w - y)^2$ and a random variable $Z$ with $\mathbb{E}[Z^2] < \infty$.

Then, $\forall w \in \mathbb{R}$:

$$
\mathbb{E}[Z] < \infty \implies
\begin{aligned}
\mathbb{E}[(w - Z)^2]
&= w^2 - 2w\mathbb{E}[Z] + \mathbb{E}[Z^2] \\
&= w^2 - 2w\mathbb{E}[Z] + \mathbb{E}[Z^2] - (\mathbb{E}[Z])^2 + (\mathbb{E}[Z])^2 \\
&= (w - \mathbb{E}[Z])^2 + \operatorname{Var}(Z)
\end{aligned}
$$

so the mapping $w \mapsto \mathbb{E}[(w - Z)^2]$ is <b>strictly convex</b> with:
- a unique minimizer $w = \mathbb{E}[Z]$ _(under square loss: the best constant prediction of $Z$ is its mean)_
- a minimal value of $\operatorname{Var}(Z) = \mathbb{E}[(Z - \mathbb{E}[Z])^2] = \mathbb{E}[Z^2] - (\mathbb{E}[Z])^2$ _(the minimal possible error is its variance)_

We now assume $\mathbb{E}[Y^2] < \infty$, _by disintegration we obtain:_

$$
\begin{aligned}
\mathbb{E}[Y^2]
&= \int_{\mathcal{X}\times\mathcal{Y}} y^2\,\rho(dx,dy) \\
&= \int_{\mathcal{X}}
\left(
\int_{\mathcal{Y}} y^2\,\rho_{Y\mid X}(dy\mid x)
\right)\rho_X(dx).
\end{aligned}
$$

Therefore we have

$$
\int_{\mathcal{Y}} y^2\,\rho_{Y\mid X}(dy\mid x)<\infty
$$

for $\rho_X$-almost every $x\in\mathcal{X}$. By the Cauchy–Schwarz inequality, this also implies

$$
\int_{\mathcal{Y}} |y|\,\rho_{Y\mid X}(dy\mid x)<\infty
$$

for $\rho_X$-almost every $x\in\mathcal{X}$.

The conditional risk under squared loss is then:

$$
R_x(w) = \mathbb{E}[(w-Y)^2\mid X=x] = \bigl(w-\mathbb{E}[Y\mid X=x]\bigr)^2 + \operatorname{Var}(Y\mid X=x).
$$

The second term does not depend on $w$, and the first one is minimized when:

$$
w=\mathbb{E}[Y\mid X=x].
$$

Therefore, the unique minimizer is:

$$
\bar f(x) = \int_{\mathcal{Y}} y\,\rho_{Y\mid X}(dy\mid x) = \mathbb{E}[Y\mid X=x].
$$

Then, we easily obtain <b>the least-squares regression function</b> and its minimum loss (risk):

$$
\bar f(X)=\mathbb{E}[Y\mid X],
$$
and

$$
\mathbb{E}[\ell(\bar f(X),Y)] = \mathbb{E}\left[(Y-\mathbb{E}[Y\mid X])^2\right] = \operatorname{Var}(Y) - \operatorname{Var}(\mathbb{E}[Y\mid X]).
 $$

<b>Example: pinball loss</b>

We now consider $\mathcal{Y} \subseteq \mathbb{R}$ and a loss function $l(w, y) = l_\alpha(y - w)$, with $\alpha \in (0,1)$ and the <b>pinball loss function</b> defined as:

$$
l_\alpha(u) = \bigl(\alpha - \mathbf{1}_{\{u < 0\}}\bigr)u =
\begin{cases}
\alpha u, & \text{if } u \geq 0, \\
(\alpha - 1)u, & \text{if } u < 0.
\end{cases}
$$

In this formula, $\alpha$ is the <b>quantile</b> we want to predict and it determines the asymmetry of the loss. Indeed, in the pinball loss function, the penalty is proportional to $1- \alpha$, therefore:
- for $\alpha > 1/2$: _underprediction_ is penalized more
- for $\alpha < 1/2$: _overprediction_ is penalized more
- for $\alpha = 1/2$: _both directional_ errors have the same cost

We firstly note that:
- $\partial_+ \ell_{\alpha}(\mu) = \alpha - \mathbf{1}_{\{\mu < 0\}}$
- $\partial_- \ell_{\alpha}(\mu) = \alpha - \mathbf{1}_{\{\mu \leq 0\}}$

We now consider a random variable $Z$ with $\mathbb{E}[|Z|] < \infty$. In this case, $\mathbb{E}[\ell_\alpha(Z - w)]$ is convex in $w$ and:
- $\delta_+ \mathbb{E}[\ell_\alpha(Z - w)] = \mathbb{P}[Z \leq w] - \alpha$
- $\delta_- \mathbb{E}[\ell_\alpha(Z - w)] = \mathbb{P}[Z < w] - \alpha$

So $w$ is a minimizer of $\mathbb{E}[\ell_\alpha(Z - w)]$ if and only if $\mathbb{P}[Z < w] \leq \alpha$ and $\mathbb{P}[Z \leq w] \geq \alpha$, if and only if $w$ is an $\alpha$-quantile of $Z$.

Now let $q_\alpha(x)$, for $x \in \mathcal{X}$, be an $\alpha$-quantile of the conditional distribution $\rho_{Y \mid X}(\cdot \mid x)$. Then we have:
- $\bar f(x) = q_\alpha(x)$
- $\mathbb{E}[\ell(\bar f(X), Y)] = \mathbb{E}[\ell_\alpha(Y - q_\alpha(X))]$ _(quantile regression)_

For the special case $\alpha = 1/2$, $q_{1/2}(Z)$ is a median of $Z$, and
$\mathbb{E}[\ell_{1/2}(Y - q_{1/2}(X))] = \frac{1}{2}\mathbb{E}[|Y - q_{1/2}(X)|]$ is the <b>minimal MAE</b>.

---

<b>Empirical loss (empirical risk)</b>

Let $(X_i, Y_i)$ with $i = 1,\ldots,m$ be _independent copies_ of $(X,Y)$, called training data.

The empirical loss/risk of a measurable function $f: \mathcal{X} \to \mathcal{Y}$ is $\frac{1}{m} \sum_{i=1}^m \ell(f(X_i), Y_i) \approx \mathbb{E}[\ell(f(X),Y)]$. In the case of $\mathbb{E}[\ell^2(f(X),Y)] < \infty$, we can write:

$$
\begin{aligned}
\mathbb{E}\left[\left(\frac{1}{m} \sum_{i=1}^m \ell(f(X_i), Y_i) - \mathbb{E}[\ell(f(X),Y)]\right)^2\right]
&= \operatorname{Var}\left(\frac{1}{m} \sum_{i=1}^m \ell(f(X_i), Y_i)\right) \\
&= \frac{1}{m^2} \sum_{i=1}^m \operatorname{Var}(\ell(f(X_i), Y_i)) \\
&= \frac{1}{m}\operatorname{Var}(\ell(f(X),Y)) \xrightarrow[m \to \infty]{} 0
\end{aligned}
$$

and we can call this <b>weak law of large numbers</b>.

_Intuition: with the training data growing, variance approaches zero_.

---

<b>Hypothesis Classes</b>

A hypothesis class is a family $\mathcal{H}$ of measurable functions $f: \mathcal{X} \to \mathcal{Y}$, e.g.:
- all affine functions _(i.e. weighted sums of features $X_i$)_
- 2nd order polynomials
- <a href="https://en.wikipedia.org/wiki/Spline_(mathematics)" target="_blank">splines</a>  (local polynomial pieces joined together, producing a smooth flexible curve)
- trees _(sequential if-then rules with piecewise constant regions)_
- support vector machines _(separate classes with a maximum-margin boundary)_
- neural networks _(several nonlinear transformations)_

Ideally, we would like to minimize $\mathbb{E}[\ell(f(X),Y)]$ over all measurable functions $f$.

However, in practice, we try to find a <b>numerical solution</b> $\hat f_m$ to the empirical loss minimization problem:

$$
\min_{f \in \mathcal{H}} \frac{1}{m} \sum_{i=1}^m \ell(f(X_i), Y_i)
$$

Note that $\hat f_m$ can be produced by either:
- a <b>deterministic algorithm</b>, in the form $\hat f_m = \hat \phi(\cdot, (X_i,Y_i)_{i=1}^m)$, where $\hat \phi$ is a measurable function of the training data;
- a <b>stochastic optimization algorithm</b>, in the form $\hat f_m = \hat \phi(\cdot, (X_i,Y_i)_{i=1}^m, V)$, where $V$ is a random element independent of the training data and $\hat \phi$ is measurable _(note that a stochastic algorithm can produce different results with the same training data due to the presence of the noisy term $V$)_

Given the numerical solution $\hat f_m$, we now formalize the <b>expected loss decomposition</b> for the square loss function.
<br/>We first define the <b>conditional expected loss given that $X = x$</b>:

$$
\begin{aligned}
\mathbb{E}[(\hat f_m(X) - Y)^2 \mid X = x]
&= \mathbb{E}[(\hat f_m(x) - Y)^2 \mid X = x] \\
&= \mathbb{E}[(\hat f_m(x) - \bar f(x))^2]
    + \int_{\mathcal{Y}} (\bar f(x) - y)^2 \, \rho_{Y \mid X}(dy \mid x).
\end{aligned}
$$

If we define:
- $\hat f_m^{\mathrm{avg}}(x) = \mathbb{E}[\hat f_m(x)]$
- $\bar f(x) = \int_{\mathcal{Y}} y \, \rho_{Y \mid X}(dy \mid x) = \mathbb{E}[Y \mid X = x]$

then we can write the conditional expected loss as:

$$
\begin{aligned}
\mathbb{E}[(\hat f_m(X) - Y)^2 \mid X = x]
&= \bigl(\hat f_m^{\mathrm{avg}}(x) - \bar f(x)\bigr)^2 \\
&\quad + \mathbb{E}\left[(\hat f_m(x) - \hat f_m^{\mathrm{avg}}(x))^2\right] \\
&\quad + \int_{\mathcal{Y}} (\bar f(x) - y)^2 \, \rho_{Y \mid X}(dy \mid x).
\end{aligned}
$$

The first term is the <b>conditional bias squared</b>, the second term is the <b>conditional variance</b>, and the last term is the <b>conditional irreducible error</b>.

Furthermore, the expected loss is _(the calculations are omitted for economy of space; readers are encouraged to compute them by hand):_

$$
\begin{aligned}
\mathbb{E}[(\hat f_m(X) - Y)^2]
&= \mathbb{E}\left[(\hat f_m^{\mathrm{avg}}(X) - \bar f(X))^2\right] \\
&\quad + \mathbb{E}\left[(\hat f_m(X) - \hat f_m^{\mathrm{avg}}(X))^2\right] \\
&\quad + \mathbb{E}\left[(\bar f(X) - Y)^2\right].
\end{aligned}
$$

The first term is the <b>average bias squared</b>, the second term is the <b>average variance</b>, and the last term is the <b>irreducible error</b>.

For a given size $m$ of the training set, we can then define:
- the <b>bias</b> as the distance of the average prediction function $\hat f_m^{\mathrm{avg}}$ from the true regression function $\bar f$
- the <b>variance</b> as the variation of the data-dependent (noisy) prediction function $\hat f_m$

and... _of course_, we should aim for a good balance between them!

<br/>
<b>Goodness of fit</b>

If we consider the same square loss function, a training data set $(X_i, Y_i)$, with $i = 1,\ldots,m$, and a test dataset $(X_i, Y_i)$, with $i = m+1,\ldots,m+n$, and $\hat f_m$ a prediction function trained on the training data, we can define the <b>in-sample goodness of fit</b> $R^2$ as:

$$
R^2 = 1 - \frac{SSR}{SST}
$$

where
- SSR = $\sum_{i=1}^m (Y_i - \hat f_m(X_i))^2$ _(sum of squared residuals)_
- SST = $\sum_{i=1}^m (Y_i - \bar Y_{\mathrm{train}})^2$, with $\bar Y_{\mathrm{train}} = \frac{1}{m} \sum_{i=1}^m Y_i$ _(total sum of squares)_

Note that, with the same approach, we can define the out-of-sample $R^2$, using $Y_i$ and $\hat f_m(X_i)$ from the testing dataset.

_As an obvious intuition, $R^2$ measures prediction power (higher is therefore better!)._

---

<br/>
<b>Approximation and Sampling Error</b>

If $\mathcal{H}$ is not flexible enough to approximate $f$ well _(i.e. the hypothesis class does not contain the ideal predictor $\bar f$)_, we can incur an <b>approximation error</b>, that measures the limitation of the current model family itself in comparison with the ideal model and it is defined as:
$$
    \text{Approx. Error} = \inf_{f \in \mathcal{H}} \mathbb{E}[\ell(f(X),Y)] - \mathbb{E}[\ell(\bar f(X),Y)] \geq 0
$$
If the empirical loss minimization problem, i.e. $\min \frac{1}{m} \sum_{i=1}^m \ell(F(X_i), Y_i)$, has a solution, we call that solution $\hat f_m^{\mathcal{H}} \in \mathcal{H}$ (note that in this case $\hat f_m^{\mathcal{H}}$ is random, since it depends on $(X_1,Y_1),\ldots,(X_m,Y_m)$).

If $\hat f_m^{\mathcal{H}}$ exists, it is random because it depends on the random training sample. In this case, its <b>sampling error (estimation error)</b> is the difference between its true loss and the population loss available in $\mathcal{H}$ _(it results from minimizing the empirical loss instead of the expected loss; it typically decreases with increasing sample size $m$)_, i.e.:

$$
    \text{Sampling Error}
= \mathbb{E}[\ell(\hat f_m^{\mathcal{H}}(X),Y)]
- \inf_{f \in \mathcal{H}} \mathbb{E}[\ell(f(X),Y)] \\
= \int_{\mathcal{X} \times \mathcal{Y}} \ell(\hat f_m^{\mathcal{H}}(x),y) \, \rho(dx,dy)
- \inf_{f \in \mathcal{H}} \int_{\mathcal{X} \times \mathcal{Y}} \ell(f(x),y) \, \rho(dx,dy) \geq 0
$$

---
<br/>
<b>Optimization error</b>

Consider a numerical solution $\hat f_m$ of $\inf_{f \in \mathcal{H}} \frac{1}{m} \sum_{i=1}^m \ell(f(X_i), Y_i)$, with:
- $\hat f_m = \phi(\cdot, (X_i, Y_i)_{i=1}^m, V)$
- measurable $\phi$ and a $\mathcal{V}$-valued random element $V$ independent of $(X,Y)$.

We can then define the <b>direct optimization error</b> as:

$$
    \text{Direct Optim. Error} = \frac{1}{m} \sum_{i=1}^m \ell(\hat f_m(X_i),Y_i)- \inf_{f \in \mathcal{H}} \frac{1}{m} \sum_{i=1}^m \ell(f(X_i),Y_i)
\geq 0
$$

Note that the first term is the empirical loss achieved by the numerical solution, the second is the lowest empirical loss achievable by any function in $\mathcal{H}$. Note also that this error is different _from the sampling error_:
- the optimization error measures failure to solve the training problem
- the sampling error measures the gap between training performance and test data performance

---
<br/>
<b>Decomposition of the Generalization Error</b>

Once we have defined the previous metrics, we can define the following:

$$
\begin{aligned}
\text{Generalization Error:}\quad
\mathbb{E}\left[
\ell\left(\hat f_m(X),Y\right)
\,\middle|\, \hat f_m
\right]
&=
\int_{\mathcal{X}\times\mathcal{Y}}
\ell\left(\hat f_m(x),y\right)\,\rho(dx,dy)
\\
&=
\underbrace{
\mathbb{E}\left[\ell\left(\bar f(X),Y\right)\right]
}_{\text{irreducible error}}
\\
&\quad+
\underbrace{
\inf_{f\in\mathcal{H}}
\mathbb{E}\left[\ell(f(X),Y)\right]
-
\mathbb{E}\left[\ell\left(\bar f(X),Y\right)\right]
}_{\text{approximation error}}
\\
&\quad+
\underbrace{
\mathbb{E}\left[
\ell\left(\hat f_m^{\mathcal{H}}(X),Y\right)
\,\middle|\, \hat f_m^{\mathcal{H}}
\right]
-
\inf_{f\in\mathcal{H}}
\mathbb{E}\left[\ell(f(X),Y)\right]
}_{\text{sampling error}}
\\
&\quad+
\underbrace{
\mathbb{E}\left[
\ell\left(\hat f_m(X),Y\right)
\,\middle|\, \hat f_m
\right]
-
\mathbb{E}\left[
\ell\left(\hat f_m^{\mathcal{H}}(X),Y\right)
\,\middle|\, \hat f_m^{\mathcal{H}}
\right]
}_{\substack{\text{indirect optimization error}\\
\text{(can be positive or negative)}}}.
\end{aligned}
$$

For a given $m$ and an increasing $\mathcal{H}$ _(i.e. the set of models we can choose from is increasing)_:
- approximation error is decreasing
- sampling error tends to increase
- there's a tradeoff between approximation error and sampling error _(similar to the bias-variance tradeoff)_
- for small data $\mathcal{H}$ should be simple _(and for big data, it can be complex!)_

---
<br/>
<b>Training Error and Test Error</b>

Once we have defined $\hat f_m$, we condition on it and so it is _no longer_ random.

If we consider training and test data sets, we can define:

$$
E_{\mathrm{tr}} = \frac{1}{m}\sum_{i=1}^m \ell(\hat f_m(X_i),Y_i), \qquad
E_{\mathrm{te}} = \frac{1}{n}\sum_{i=m+1}^{m+n} \ell(\hat f_m(X_i),Y_i)
$$

If $E_{\mathrm{tr}}$ is significantly smaller than $E_{\mathrm{te}}$, the model is most likely <b>overfitted</b>.

We can then calculate the <b>sample variance</b>:

$$
\sigma^2_{\mathrm{te}} = \frac{1}{n-1} \sum_{i=m+1}^{m+n}
\left(\ell(\hat f_m(X_i),Y_i) - E_{\mathrm{te}}\right)^2
$$

which, if $\mathbb{E}[\ell^2(\hat f_m(X),Y) \mid \hat f_m] < \infty$, follows the <b>Law of Large Numbers</b> and converges, as $n \to \infty$, to $\operatorname{Var}(\ell(\hat f_m(X),Y) \mid \hat f_m)$.

Furthermore, by the <b>Central Limit Theorem</b>, we have:

$$
E_{\mathrm{te}} - \mathbb{E}[\ell(\hat f_m(X),Y) \mid \hat f_m]
\sim \mathcal{N}\left(0, \frac{\sigma^2_{\mathrm{te}}}{n}\right).
$$

Therefore, we have the following property:

$$
\mathbb{P}\left[
E_{\mathrm{te}} - \frac{\sigma_{\mathrm{te}}}{\sqrt{n}} q_{1-\alpha / 2}
\leq \mathbb{E}[\ell(\hat f_m(X),Y) \mid \hat f_m]
\leq E_{\mathrm{te}} + \frac{\sigma_{\mathrm{te}}}{\sqrt{n}} q_{1-\alpha / 2}
\right] \approx 1 - \alpha
$$

That is a confidence interval with confidence level $1 - \alpha$, where $q_{1-\alpha/2}$ is the $(1 - \alpha/2)$-quantile of the standard normal distribution.

We now come back to the <b>overfitting problem</b>: what can we do about it? Firstly, we can reduce the complexity of the hypothesis class, i.e. by considering simpler models. _Alternatively_, we can <b>regularize</b> the empirical loss minimization problem by <b>penalizing</b> the complexity of potential prediction functions $f \in \mathcal{H}$, which, _practically speaking_, means:

$$
\inf_{f \in \mathcal{H}} \frac{1}{m} \sum_{i=1}^m \ell(f(X_i),Y_i) + \lambda_1 \lVert f \rVert_1 + \lambda_2 \lVert f \rVert_2^2
$$

for hyperparameters $\lambda_1 \geq 0$ _(strength of the Lasso penalty)_, $\lambda_2 \geq 0$ _(strength of the ridge penalty)_.

We call $\lambda_1 \lVert f \rVert_1$ <b>LASSO</b> and $\lambda_2 \lVert f \rVert_2^2$ <b>ridge regression</b>; together, they compose the <b>elastic net</b>.

_In general_, LASSO penalizes the absolute value of the coefficients and can set them to zero, and it is defined as:

$$
\lambda_1 \lVert \beta \rVert_1 = \lambda_1 \sum_{j=1}^d |\beta_j|.
$$

Therefore, LASSO performs feature selection, i.e. limits the features with lower explanatory power.

_On the other hand_, ridge regression defines a penalty equal to:

$$
\lambda_2 \lVert \beta \rVert_2^2 = \lambda_2 \sum_{j=1}^d \beta_j^2.
$$

It discourages large coefficients but does not make them exactly zero; it smoothly shrinks them around zero.

Ridge regression can be useful when features are correlated. In this situation, LASSO may select one feature and discard another similar one, while ridge tends to distribute the coefficients across them.

When both penalties are present, the method is called <b>elastic net</b>, since it combines LASSO's ability to set coefficients to zero and ridge regression's shrinkage of correlated features.
