## <a id="1"><b>1 Basic Notions of Statistical Learning</b></a>

<b>Definition of a $\sigma$-algebra</b>

_Firstly,_ we remember that a $\sigma$-algebra $\mathcal{F}$ is a non-empty collection of subsets of $\Omega$ that contains $\Omega$ itself and is closed under complementation and countable unions, i.e. it satisfies the following:
- contains the whole space $\Omega \in \mathcal{F}$
- closed under complementation: $\text{If } A \in \mathcal{F}, \text{ then } A^c = \Omega \setminus A \in \mathcal{F}$
- it is closed under countable unions: $\text{If } A_1, A_2, A_3, \dots \in \mathcal{F}, \text{ then } \bigcup_{n=1}^{\infty} A_n \in \mathcal{F}$

From this definition, we give some examples:
- <b>Trivial $\sigma$-algebra</b>: $\mathcal{F} = \{\emptyset, \Omega\}$ _(the smallest $\sigma$-algebra)_
- <b>Power set</b>: $\mathcal{F} = \mathcal{P}(\Omega)$ _(collection of all subsets of $\Omega$, the largest possible $\sigma$-algebra)_
- <b>Borel $\sigma$-algebra</b> _(smallest $\sigma$-algebra generated by all open sets in $\mathbb{R}$, it is the essential foundation for measure theory and real analysis)_

_Intuition: in $\mathbb{R}$, consider all the intervals $(a,b)$ and perform all three actions that define the $\sigma$-algebra (complements, countable unions, countable intersections, where the last one nicely derives from the definition of $\sigma$-algebra): the resulting set is the Borel $\sigma$-algebra $\mathcal{B}(\mathbb{R})$ and represents every subset of $\mathbb{R}$ that can be obtained using standard mathematical operations)._

We also recall that a function $f: X \to Y$ is <b>Borel measurable</b> if:

$$
f^{-1}(B) = \{x \in X : f(x) \in B\} \in \mathcal{B}(X) \quad \text{for every } B \in \mathcal{B}(Y)
$$
_Intuition: if the preimage of every Borel set in $Y$ is a Borel set in $X$._

<br/>
<b>The prediction problem</b>
<br/>
Consider the following:
- a probability space $(\Omega, \mathcal{F}, \mathbb{P})$, i.e.:
    - a non-empty set $\Omega$, the _sample space_
    - $\mathcal{F}$, a $\sigma$-algebra of subsets of $\Omega$,
    - a probability measure $\mathbb{P} : \mathcal{F} \to [0,1]$
- a feature space $\mathcal{X} \subseteq \mathbb{R}^d$ with Borel $\sigma$-algebra $\mathbb{B}_{\mathcal{X}}$ _(example: $\mathcal{X} = \mathbb{R}^m \times \{1,2,\ldots,n\} \times \mathbb{N}$)_
- a closed or open target space $\mathcal{Y} \subseteq \mathbb{R}^k$ with Borel $\sigma$-algebra $\mathbb{B}_{\mathcal{Y}}$ _(example: $\mathcal{Y} = \mathbb{R}$)_
- some random elements $X : \Omega \to \mathcal{X}$ _(inputs)_, $Y : \Omega \to \mathcal{Y}$ _(outputs)_




We then consider $\rho_X$, $\rho_Y$, and $\rho$ as the distributions of $X$, $Y$, and $(X,Y)$, respectively, and $\rho_{Y \mid X}$ as the <b>regular conditional distribution</b> of $Y$ given $X$, that is:
- $\forall x \in \mathcal{X}: \rho_{Y \mid X}(\cdot \mid x)$ is a probability measure on $\mathcal{Y}$
- $\forall B \in \mathbb{B}_{\mathcal{Y}}$, $x \mapsto \rho_{Y \mid X}(B \mid x)$ is $\mathbb{B}_{\mathcal{X}}$-measurable
- $\forall B \in \mathbb{B}_{\mathcal{Y}}$, $\mathbb{E}[\mathbf{1}_B(Y) \mid X] = \rho_{Y \mid X}(B \mid X)$ $\mathbb{P}$-almost surely.

It then follows that, for all $\rho$-integrable $h: \mathcal{X} \times \mathcal{Y} \to \mathbb{R}$, we have the <b>disintegration of $\rho$</b>:
$$
\int_{\mathcal{X} \times \mathcal{Y}} h(x, y) \, \rho(dx, dy) = \int_{\mathcal{X}}\int_{\mathcal{Y}} h(x, y) \, \rho_{Y \mid X}(dy \mid x) \, \rho_X(dx)
$$


We now go back to the prediction problem: we want to find a measurable function $f: \mathcal{X} \to \mathcal{Y}$ s.t. $f(X) \approx Y$, i.e. a function that allows us to minimize the <b>expected loss</b> (also called <b>risk</b>), defined as:

$$
\mathbb{E}[\ell(f(X), Y)] = \int_{\mathcal{X} \times \mathcal{Y}} \ell(f(x), y) \, \rho(dx, dy)
$$

for a measurable loss function $\ell: \mathcal{Y} \times \mathcal{Y} \to \mathbb{R}_+$.

Then, _in machine learning_, it is common to solve the <b>empirical loss minimization problem</b>!

<b>Regression Functions and Irreducible Error</b>
<br/>
<b>Lemma (theoretically best predictor with respect to a given loss function $\ell: \mathcal{Y} \times \mathcal{Y} \to \mathbb{R}_+$)</b>

Let $\bar f: \mathcal{X} \to \mathcal{Y}$ be a measurable function such that, for $\rho_X$-almost every $x \in \mathcal{X}$, $\bar f(x)$ minimizes

$$
w \mapsto \int_{\mathcal{Y}} \ell(w,y)\,\rho_{Y\mid X}(dy\mid x)
\in [0,+\infty].
$$

Then

$$
\mathbb{E}[\ell(\bar f(X),Y)]
\leq
\mathbb{E}[\ell(f(X),Y)]
$$

for every measurable function $f:\mathcal{X}\to\mathcal{Y}$.

Note that $\bar f(x)$ is the _ideal predictor_ we would use if we knew the true conditional distribution of $Y$ given $X=x$. For each $x\in\mathcal X$, if we predict a value $w\in\mathcal Y$, the conditional expected loss is

$$
R_x(w) = \mathbb E[\ell(w,Y)\mid X=x] =
\int_{\mathcal Y} \ell(w,y)\,\rho_{Y\mid X}(dy\mid x).
$$

The function $\bar f$ chooses the prediction that minimizes this conditional risk:

$$
\bar f(x) \in \operatorname*{argmin}_{w\in\mathcal Y} R_x(w).
$$

_From now on_, we suppose these assumptions from the lemma hold and we call:
- $\bar f$ <b>regression function</b> _(or, more generally, the Bayesian-optimal predictor)_
- $\mathbb{E}[\ell(\bar f(X),Y)]$ <b>irreducible error</b> _(even with the exact conditional distribution, randomness in $Y$ given $X$ can prevent perfect prediction)_

---
<br/>
<b>Example: Square loss </b>

We now consider the following example with $\mathcal{Y} \subseteq \mathbb{R}$, $\ell(w,y) = (w - y)^2$ and a random variable $Z$ with $\mathbb{E}[Z^2] < \infty$.

Then, $\forall w \in \mathbb{R}$:

$$
\mathbb{E}[Z] < \infty \implies
\begin{aligned}
\mathbb{E}[(w - Z)^2]
&= w^2 - 2w\mathbb{E}[Z] + \mathbb{E}[Z^2] \\
&= w^2 - 2w\mathbb{E}[Z] + \mathbb{E}[Z^2] - (\mathbb{E}[Z])^2 + (\mathbb{E}[Z])^2 \\
&= (w - \mathbb{E}[Z])^2 + \operatorname{Var}(Z)
\end{aligned}
$$

so the mapping $w \mapsto \mathbb{E}[(w - Z)^2]$ is <b>strictly convex</b> with:
- a unique minimizer $w = \mathbb{E}[Z]$ _(under square loss: the best constant prediction of $Z$ is its mean)_
- a minimal value of $\operatorname{Var}(Z) = \mathbb{E}[(Z - \mathbb{E}[Z])^2] = \mathbb{E}[Z^2] - (\mathbb{E}[Z])^2$ _(the minimal possible error is its variance)_

We now assume $\mathbb{E}[Y^2] < \infty$, _by disintegration we obtain:_

$$
\begin{aligned}
\mathbb{E}[Y^2]
&= \int_{\mathcal{X}\times\mathcal{Y}} y^2\,\rho(dx,dy) \\
&= \int_{\mathcal{X}}
\left(
\int_{\mathcal{Y}} y^2\,\rho_{Y\mid X}(dy\mid x)
\right)\rho_X(dx).
\end{aligned}
$$

Therefore we have

$$
\int_{\mathcal{Y}} y^2\,\rho_{Y\mid X}(dy\mid x)<\infty
$$

for $\rho_X$-almost every $x\in\mathcal{X}$. By the Cauchy–Schwarz inequality, this also implies

$$
\int_{\mathcal{Y}} |y|\,\rho_{Y\mid X}(dy\mid x)<\infty
$$

for $\rho_X$-almost every $x\in\mathcal{X}$.

The conditional risk under squared loss is then:

$$
R_x(w) = \mathbb{E}[(w-Y)^2\mid X=x] = \bigl(w-\mathbb{E}[Y\mid X=x]\bigr)^2 + \operatorname{Var}(Y\mid X=x).
$$

The second term does not depend on $w$, and the first one is minimized when:

$$
w=\mathbb{E}[Y\mid X=x].
$$

Therefore, the unique minimizer is:

$$
\bar f(x) = \int_{\mathcal{Y}} y\,\rho_{Y\mid X}(dy\mid x) = \mathbb{E}[Y\mid X=x].
$$

Then, we easily obtain <b>the least-squares regression function</b> and its minimum loss (risk):

$$
\bar f(X)=\mathbb{E}[Y\mid X],
$$
and

$$
\mathbb{E}[\ell(\bar f(X),Y)] = \mathbb{E}\left[(Y-\mathbb{E}[Y\mid X])^2\right] = \operatorname{Var}(Y) - \operatorname{Var}(\mathbb{E}[Y\mid X]).
 $$

<br/>
<b>Example: pinball loss</b>

We now consider $\mathcal{Y} \subseteq \mathbb{R}$ and a loss function $\ell(w, y) = \ell_\alpha(y - w)$, with $\alpha \in (0,1)$ and the <b>pinball loss function</b> defined as:

$$
\ell_\alpha(u) = \bigl(\alpha - \mathbf{1}_{\{u < 0\}}\bigr)u =
\begin{cases}
\alpha u, & \text{if } u \geq 0, \\
(\alpha - 1)u, & \text{if } u < 0.
\end{cases}
$$

In this formula, $\alpha$ is the <b>quantile</b> we want to predict and it determines the asymmetry of the loss. Indeed, in the pinball loss function, the penalty is proportional to $1- \alpha$, therefore:
- for $\alpha > 1/2$: _underprediction_ is penalized more
- for $\alpha < 1/2$: _overprediction_ is penalized more
- for $\alpha = 1/2$: _errors in both directions_ have the same cost

We first note that:
- $\partial_+ \ell_{\alpha}(\mu) = \alpha - \mathbf{1}_{\{\mu < 0\}}$
- $\partial_- \ell_{\alpha}(\mu) = \alpha - \mathbf{1}_{\{\mu \leq 0\}}$

We now consider a random variable $Z$ with $\mathbb{E}[|Z|] < \infty$. In this case, $\mathbb{E}[\ell_\alpha(Z - w)]$ is convex in $w$ and:
- $\delta_+ \mathbb{E}[\ell_\alpha(Z - w)] = \mathbb{P}[Z \leq w] - \alpha$
- $\delta_- \mathbb{E}[\ell_\alpha(Z - w)] = \mathbb{P}[Z < w] - \alpha$

So $w$ is a minimizer of $\mathbb{E}[\ell_\alpha(Z - w)]$ if and only if $\mathbb{P}[Z < w] \leq \alpha$ and $\mathbb{P}[Z \leq w] \geq \alpha$, if and only if $w$ is an $\alpha$-quantile of $Z$.

Now let $q_\alpha(x)$, for $x \in \mathcal{X}$, be an $\alpha$-quantile of the conditional distribution $\rho_{Y \mid X}(\cdot \mid x)$. Then we have:
- $\bar f(x) = q_\alpha(x)$
- $\mathbb{E}[\ell(\bar f(X), Y)] = \mathbb{E}[\ell_\alpha(Y - q_\alpha(X))]$ _(quantile regression)_

For the special case $\alpha = 1/2$, $q_{1/2}(Z)$ is a median of $Z$, and
$\mathbb{E}[\ell_{1/2}(Y - q_{1/2}(X))] = \frac{1}{2}\mathbb{E}[|Y - q_{1/2}(X)|]$ is the <b>minimal MAE</b>.

---
<br/>
<b>Empirical loss (empirical risk)</b>

Let $(X_i, Y_i)$ with $i = 1,\ldots,m$ be _independent copies_ of $(X,Y)$, called training data.

The empirical loss/risk of a measurable function $f: \mathcal{X} \to \mathcal{Y}$ is $\frac{1}{m} \sum_{i=1}^m \ell(f(X_i), Y_i) \approx \mathbb{E}[\ell(f(X),Y)]$. In the case of $\mathbb{E}[\ell^2(f(X),Y)] < \infty$, we can write:

$$
\begin{aligned}
\mathbb{E}\left[\left(\frac{1}{m} \sum_{i=1}^m \ell(f(X_i), Y_i) - \mathbb{E}[\ell(f(X),Y)]\right)^2\right]
&= \operatorname{Var}\left(\frac{1}{m} \sum_{i=1}^m \ell(f(X_i), Y_i)\right) \\
&= \frac{1}{m^2} \sum_{i=1}^m \operatorname{Var}(\ell(f(X_i), Y_i)) \\
&= \frac{1}{m}\operatorname{Var}(\ell(f(X),Y)) \xrightarrow[m \to \infty]{} 0
\end{aligned}
$$

and we can call this the <b>weak law of large numbers</b>.

_Intuition: as the amount of training data grows, variance approaches zero_.

---
<br/>
<b>Hypothesis Classes</b>

A hypothesis class is a family $\mathcal{H}$ of measurable functions $f: \mathcal{X} \to \mathcal{Y}$, e.g.:
- all affine functions _(i.e. weighted sums of features $X_i$)_
- second-order polynomials
- <a href="https://en.wikipedia.org/wiki/Spline_(mathematics)" target="_blank">splines</a>  (local polynomial pieces joined together, producing a smooth flexible curve)
- trees _(sequential if-then rules with piecewise constant regions)_
- support vector machines _(separate classes with a maximum-margin boundary)_
- neural networks _(several nonlinear transformations)_

Ideally, we would like to minimize $\mathbb{E}[\ell(f(X),Y)]$ over all measurable functions $f$.

However, in practice, we try to find a <b>numerical solution</b> $\hat f_m$ to the empirical loss minimization problem:

$$
\min_{f \in \mathcal{H}} \frac{1}{m} \sum_{i=1}^m \ell(f(X_i), Y_i)
$$

Note that $\hat f_m$ can be produced by either:
- a <b>deterministic algorithm</b>, in the form $\hat f_m = \hat \phi(\cdot, (X_i,Y_i)_{i=1}^m)$, where $\hat \phi$ is a measurable function of the training data;
- a <b>stochastic optimization algorithm</b>, in the form $\hat f_m = \hat \phi(\cdot, (X_i,Y_i)_{i=1}^m, V)$, where $V$ is a random element independent of the training data and $\hat \phi$ is measurable _(note that a stochastic algorithm can produce different results with the same training data due to the presence of the noisy term $V$)_

Given the numerical solution $\hat f_m$, we now formalize the <b>expected loss decomposition</b> for the square loss function.
<br/>We first define the <b>conditional expected loss given that $X = x$</b>:

$$
\begin{aligned}
\mathbb{E}[(\hat f_m(X) - Y)^2 \mid X = x]
&= \mathbb{E}[(\hat f_m(x) - Y)^2 \mid X = x] \\
&= \mathbb{E}[(\hat f_m(x) - \bar f(x))^2]
    + \int_{\mathcal{Y}} (\bar f(x) - y)^2 \, \rho_{Y \mid X}(dy \mid x).
\end{aligned}
$$

If we define:
- $\hat f_m^{\mathrm{avg}}(x) = \mathbb{E}[\hat f_m(x)]$
- $\bar f(x) = \int_{\mathcal{Y}} y \, \rho_{Y \mid X}(dy \mid x) = \mathbb{E}[Y \mid X = x]$

then we can write the conditional expected loss as:

$$
\begin{aligned}
\mathbb{E}[(\hat f_m(X) - Y)^2 \mid X = x]
&= \bigl(\hat f_m^{\mathrm{avg}}(x) - \bar f(x)\bigr)^2 \\
&\quad + \mathbb{E}\left[(\hat f_m(x) - \hat f_m^{\mathrm{avg}}(x))^2\right] \\
&\quad + \int_{\mathcal{Y}} (\bar f(x) - y)^2 \, \rho_{Y \mid X}(dy \mid x).
\end{aligned}
$$

The first term is the <b>conditional bias squared</b>, the second term is the <b>conditional variance</b>, and the last term is the <b>conditional irreducible error</b>.

Furthermore, the expected loss is _(the calculations are omitted for economy of space; readers are encouraged to compute them by hand):_

$$
\begin{aligned}
\mathbb{E}[(\hat f_m(X) - Y)^2]
&= \mathbb{E}\left[(\hat f_m^{\mathrm{avg}}(X) - \bar f(X))^2\right] \\
&\quad + \mathbb{E}\left[(\hat f_m(X) - \hat f_m^{\mathrm{avg}}(X))^2\right] \\
&\quad + \mathbb{E}\left[(\bar f(X) - Y)^2\right].
\end{aligned}
$$

The first term is the <b>average bias squared</b>, the second term is the <b>average variance</b>, and the last term is the <b>irreducible error</b>.

For a given size $m$ of the training set, we can then define:
- the <b>bias</b> as the distance of the average prediction function $\hat f_m^{\mathrm{avg}}$ from the true regression function $\bar f$
- the <b>variance</b> as the variation of the data-dependent (noisy) prediction function $\hat f_m$

and... _of course_, we should aim for a good balance between them!

<br/>
<b>Goodness of fit</b>

If we consider the same square loss function, a training data set $(X_i, Y_i)$, with $i = 1,\ldots,m$, and a test dataset $(X_i, Y_i)$, with $i = m+1,\ldots,m+n$, and $\hat f_m$ a prediction function trained on the training data, we can define the <b>in-sample goodness of fit</b> $R^2$ as:

$$
R^2 = 1 - \frac{SSR}{SST}
$$

where
- SSR = $\sum_{i=1}^m (Y_i - \hat f_m(X_i))^2$ _(sum of squared residuals)_
- SST = $\sum_{i=1}^m (Y_i - \bar Y_{\mathrm{train}})^2$, with $\bar Y_{\mathrm{train}} = \frac{1}{m} \sum_{i=1}^m Y_i$ _(total sum of squares)_

Note that, with the same approach, we can define the out-of-sample $R^2$, using $Y_i$ and $\hat f_m(X_i)$ from the testing dataset.

_As an obvious intuition, $R^2$ measures prediction power (higher is therefore better!)._

---

<br/>
<b>Approximation and Sampling Error</b>

If $\mathcal{H}$ is not flexible enough to approximate $f$ well _(i.e. the hypothesis class does not contain the ideal predictor $\bar f$)_, we can incur an <b>approximation error</b>, that measures the limitation of the current model family itself in comparison with the ideal model and it is defined as:
$$
    \text{Approx. Error} = \inf_{f \in \mathcal{H}} \mathbb{E}[\ell(f(X),Y)] - \mathbb{E}[\ell(\bar f(X),Y)] \geq 0
$$
If the empirical loss minimization problem, i.e. $\min \frac{1}{m} \sum_{i=1}^m \ell(f(X_i), Y_i)$, has a solution, we call that solution $\hat f_m^{\mathcal{H}} \in \mathcal{H}$ (note that in this case $\hat f_m^{\mathcal{H}}$ is random, since it depends on $(X_1,Y_1),\ldots,(X_m,Y_m)$).

If $\hat f_m^{\mathcal{H}}$ exists, it is random because it depends on the random training sample. In this case, its <b>sampling error (estimation error)</b> is the difference between its true loss and the population loss available in $\mathcal{H}$ _(it results from minimizing the empirical loss instead of the expected loss; it typically decreases with increasing sample size $m$)_, i.e.:

$$
\begin{aligned}
\text{Sampling Error}
&= \mathbb{E}[\ell(\hat f_m^{\mathcal{H}}(X),Y)]
- \inf_{f \in \mathcal{H}} \mathbb{E}[\ell(f(X),Y)] \\
&= \int_{\mathcal{X} \times \mathcal{Y}} \ell(\hat f_m^{\mathcal{H}}(x),y) \, \rho(dx,dy)
- \inf_{f \in \mathcal{H}} \int_{\mathcal{X} \times \mathcal{Y}} \ell(f(x),y) \, \rho(dx,dy) \geq 0
\end{aligned}
$$

---
<br/>
<b>Optimization error</b>

Consider a numerical solution $\hat f_m$ of $\inf_{f \in \mathcal{H}} \frac{1}{m} \sum_{i=1}^m \ell(f(X_i), Y_i)$, with:
- $\hat f_m = \phi(\cdot, (X_i, Y_i)_{i=1}^m, V)$
- measurable $\phi$ and a $\mathcal{V}$-valued random element $V$ independent of $(X,Y)$.

We can then define the <b>direct optimization error</b> as:

$$
    \text{Direct Optim. Error} = \frac{1}{m} \sum_{i=1}^m \ell(\hat f_m(X_i),Y_i)- \inf_{f \in \mathcal{H}} \frac{1}{m} \sum_{i=1}^m \ell(f(X_i),Y_i)
\geq 0
$$

Note that the first term is the empirical loss achieved by the numerical solution, the second is the lowest empirical loss achievable by any function in $\mathcal{H}$. Note also that this error is different _from the sampling error_:
- the optimization error measures failure to solve the training problem
- the sampling error measures the gap between training performance and test data performance
<br/>
---
<br/>
<b>Decomposition of the Generalization Error</b>

Once we have defined the previous metrics, we can define the following:

$$
\begin{aligned}
\text{Generalization Error:}\quad
\mathbb{E}\left[
\ell\left(\hat f_m(X),Y\right)
\,\middle|\, \hat f_m
\right]
&=
\int_{\mathcal{X}\times\mathcal{Y}}
\ell\left(\hat f_m(x),y\right)\,\rho(dx,dy)
\\
&=
\underbrace{
\mathbb{E}\left[\ell\left(\bar f(X),Y\right)\right]
}_{\text{irreducible error}}
\\
&\quad+
\underbrace{
\inf_{f\in\mathcal{H}}
\mathbb{E}\left[\ell(f(X),Y)\right]
-
\mathbb{E}\left[\ell\left(\bar f(X),Y\right)\right]
}_{\text{approximation error}}
\\
&\quad+
\underbrace{
\mathbb{E}\left[
\ell\left(\hat f_m^{\mathcal{H}}(X),Y\right)
\,\middle|\, \hat f_m^{\mathcal{H}}
\right]
-
\inf_{f\in\mathcal{H}}
\mathbb{E}\left[\ell(f(X),Y)\right]
}_{\text{sampling error}}
\\
&\quad+
\underbrace{
\mathbb{E}\left[
\ell\left(\hat f_m(X),Y\right)
\,\middle|\, \hat f_m
\right]
-
\mathbb{E}\left[
\ell\left(\hat f_m^{\mathcal{H}}(X),Y\right)
\,\middle|\, \hat f_m^{\mathcal{H}}
\right]
}_{\substack{\text{indirect optimization error}\\
\text{(can be positive or negative)}}}.
\end{aligned}
$$

For a given $m$ and an increasing $\mathcal{H}$ _(i.e. the set of models we can choose from is increasing)_:
- approximation error is decreasing
- sampling error tends to increase
- there's a tradeoff between approximation error and sampling error _(similar to the bias-variance tradeoff)_
- for small data $\mathcal{H}$ should be simple _(and for big data, it can be complex!)_
<br/>
---
<br/>
<b>Training Error and Test Error</b>

Once we have defined $\hat f_m$, we condition on it and so it is _no longer_ random.

If we consider training and test data sets, we can define:

$$
E_{\mathrm{tr}} = \frac{1}{m}\sum_{i=1}^m \ell(\hat f_m(X_i),Y_i), \qquad
E_{\mathrm{te}} = \frac{1}{n}\sum_{i=m+1}^{m+n} \ell(\hat f_m(X_i),Y_i)
$$

If $E_{\mathrm{tr}}$ is significantly smaller than $E_{\mathrm{te}}$, the model is most likely <b>overfitted</b>.

We can then calculate the <b>sample variance</b>:

$$
\sigma^2_{\mathrm{te}} = \frac{1}{n-1} \sum_{i=m+1}^{m+n}
\left(\ell(\hat f_m(X_i),Y_i) - E_{\mathrm{te}}\right)^2
$$

which, if $\mathbb{E}[\ell^2(\hat f_m(X),Y) \mid \hat f_m] < \infty$, follows the <b>Law of Large Numbers</b> and converges, as $n \to \infty$, to $\operatorname{Var}(\ell(\hat f_m(X),Y) \mid \hat f_m)$.

Furthermore, by the <b>Central Limit Theorem</b>, we have:

$$
E_{\mathrm{te}} - \mathbb{E}[\ell(\hat f_m(X),Y) \mid \hat f_m]
\sim \mathcal{N}\left(0, \frac{\sigma^2_{\mathrm{te}}}{n}\right).
$$

Therefore, we have the following property:

$$
\mathbb{P}\left[
E_{\mathrm{te}} - \frac{\sigma_{\mathrm{te}}}{\sqrt{n}} q_{1-\alpha / 2}
\leq \mathbb{E}[\ell(\hat f_m(X),Y) \mid \hat f_m]
\leq E_{\mathrm{te}} + \frac{\sigma_{\mathrm{te}}}{\sqrt{n}} q_{1-\alpha / 2}
\right] \approx 1 - \alpha
$$

That is a confidence interval with confidence level $1 - \alpha$, where $q_{1-\alpha/2}$ is the $(1 - \alpha/2)$-quantile of the standard normal distribution.

We now come back to the <b>overfitting problem</b>: what can we do about it? First, we can reduce the complexity of the hypothesis class, i.e., by considering simpler models. _Alternatively_, we can <b>regularize</b> the empirical loss minimization problem by <b>penalizing</b> the complexity of potential prediction functions $f \in \mathcal{H}$, which, _practically speaking_, means:

$$
\inf_{f \in \mathcal{H}} \frac{1}{m} \sum_{i=1}^m \ell(f(X_i),Y_i) + \lambda_1 \lVert f \rVert_1 + \lambda_2 \lVert f \rVert_2^2
$$

for hyperparameters $\lambda_1 \geq 0$ _(strength of the Lasso penalty)_, $\lambda_2 \geq 0$ _(strength of the ridge penalty)_.

We call $\lambda_1 \lVert f \rVert_1$ <b>LASSO</b> and $\lambda_2 \lVert f \rVert_2^2$ <b>ridge regression</b>; together, they compose the <b>elastic net</b>.

_In general_, LASSO penalizes the absolute value of the coefficients and can set them to zero, and it is defined as:

$$
\lambda_1 \lVert \beta \rVert_1 = \lambda_1 \sum_{j=1}^d |\beta_j|.
$$

Therefore, LASSO performs feature selection, i.e. limits the features with lower explanatory power.

_On the other hand_, ridge regression defines a penalty equal to:

$$
\lambda_2 \lVert \beta \rVert_2^2 = \lambda_2 \sum_{j=1}^d \beta_j^2.
$$

It discourages large coefficients but does not make them exactly zero; it smoothly shrinks them around zero.

Ridge regression can be useful when features are correlated. In this situation, LASSO may select one feature and discard another similar one, while ridge tends to distribute the coefficients across them.

When both penalties are present the method is called <b>elastic net</b>, since it combines LASSO's ability to set coefficients to zero and ridge regression's shrinkage of correlated features.

<b>Ordinary Least Squares (OLS)</b>

We consider the model $Y = \beta_0 + \beta_1 X_1 + \cdots + \beta_d X_d + \epsilon$, where $\epsilon \sim \mathcal{N}(0, \sigma^2)$ is independent of $(X_1, \ldots, X_d)$.


Let $(x_{i1}, \ldots, x_{id}, y_i, \epsilon_i)$, for $i = 1, \ldots, m$, be independent and identically distributed realizations of $(X_1, \ldots, X_d, Y, \epsilon)$. In this case, we can write the model in matrix form:

$$
\begin{aligned}
y &= A\beta + \epsilon, \\
y &= \begin{pmatrix} y_1 \\ \vdots \\ y_m \end{pmatrix}, \qquad
A = \begin{pmatrix}
1 & x_{11} & \cdots & x_{1d} \\
\vdots & \vdots & & \vdots \\
1 & x_{m1} & \cdots & x_{md}
\end{pmatrix}, \\
\beta &= \begin{pmatrix} \beta_0 \\ \vdots \\ \beta_d \end{pmatrix}, \qquad
\epsilon = \begin{pmatrix} \epsilon_1 \\ \vdots \\ \epsilon_m \end{pmatrix}.
\end{aligned}
$$

Here, $A$ is the design matrix and $\beta$ is the vector of coefficients. Typically, we have $m \geq d + 1$ (i.e. we have more observations than parameters).

In this scenario, we define the <b>empirical loss minimization under the square loss function</b> _(OLS, ordinary least squares)_ as:

$$
\min_{b \in \mathbb{R}^{d+1}} \lVert Ab - y \rVert_2^2
= \min_{b \in \mathbb{R}^{d+1}} \sum_{i=1}^m \left(\sum_{j=0}^d x_{ij} b_j - y_i\right)^2,
$$

where $x_{i0} = 1$ for all $i$.

Since the function is convex in $b \in \mathbb{R}^{d+1}$, we can minimize it using partial derivatives. A minimizer $b$ satisfies

$$
\nabla_b \lVert Ab - y \rVert_2^2 = 2A^T(Ab-y)=0,
$$

which gives the following _normal equation_:

$$
A^T A b = A^T y.
$$

To solve the normal equation, we note that if the columns are <b>linearly independent</b>, $A^T A$ is invertible, and the unique solution of $A^T A b = A^T y$ is defined by:

$$
\hat \beta = (A^T A)^{-1} A^T y.
$$

If we condition $\hat{\beta}$ on $X_{ij}$ (i.e. if we rewrite $y=A\beta+\epsilon$), we obtain:

$$
\hat{\beta} = (A^T A)^{-1}A^T(A\beta+\epsilon)
= \beta + (A^T A)^{-1}A^T\epsilon
\sim \mathcal{N}_{d+1}\left(\beta,\sigma^2(A^T A)^{-1}\right).
$$

Thus, $\hat{\beta}$ has a multivariate normal distribution with mean $\beta$ and covariance matrix $\sigma^2(A^T A)^{-1}$; in other words, $\hat{\beta}$ is <b>unbiased</b>.

We also note that $A^T A$ is always a <b>symmetric positive semidefinite</b> $l \times l$ matrix, for $l=d+1$ (the number of columns of $A$). In this case, we consider the spectral decomposition of $A^T A$:

$$
A^T A = V\Lambda V^T,
$$

for an orthogonal $V \in \mathbb{R}^{l\times l}$ and a diagonal $\Lambda \in \mathbb{R}^{l\times l}$ with diagonal entries $\lambda_1 \geq \cdots \geq \lambda_l \geq 0$.

In this case, we define the <b>pseudoinverse</b> of $A$ as:

$$
(A^T A)^\dagger := V\Lambda^\dagger V^T,
\qquad
\Lambda^\dagger
=
\operatorname{diag}\left(
\mathbf{1}_{\{\lambda_j>0\}}\lambda_j^{-1}
\right)_{j=1}^{l}.
$$


<b>Lemma (columns of $A$ linearly dependent)</b>

If the columns of $A$ are linearly dependent, the normal equation $A^T A b = A^T y$ has several solutions, and

$$
\hat \beta = (A^T A)^\dagger A^T y \in \mathbb{R}^l
$$

is the solution with the smallest $\lVert\cdot\rVert_2$-norm.

_Recall that the $\lVert\cdot\rVert_2$-norm is defined as:_

$$
\lVert b \rVert_2 = \sqrt{\sum_{j=1}^{l} b_j^2}.
$$

_Recall: if the columns are linearly dependent, $\operatorname{rank}(A) < l = d + 1$ and $A^T A$ is singular, so its determinant is zero.<br/>In practical terms, this means that the coefficients are _not uniquely determined_ by the data, so the pseudoinverse then selects the coefficient vector with the smallest Euclidean norm._
<br/>_Consider, as a real-world example, that we want to predict house prices and use a model that considers both:_
- house area in square meters $X_1$
- house area in square meters $X_2$

In this case, the variables contain the same information, i.e. $X_2 \approx 10.7 X_1$, therefore the corresponding columns in the design matrix are linearly dependent and the model cannot uniquely determine separate coefficients _(in practice: one variable should be removed)_.

<b>Proof of the Lemma</b>

We want to prove that $\hat\beta = (A^T A)^\dagger A^T y$ satisfies the normal equation defined above.

Let

$$
r = \operatorname{rank}(A) = \operatorname{rank}(A^T) < \min\{m,l\}.
$$

If $A^TAv=0$, then

$$
\|Av\|_2^2 = v^T A^TAv = 0.
$$

Therefore, $Av=0$. Conversely, if $Av=0$, then $A^TAv=0$. Hence,

$$
\ker(A^TA)=\ker(A)=\{x:Ax=0\}.
$$

It follows from the rank-nullity theorem that

$$
\begin{aligned}
\dim(\operatorname{Im}(A^TA))
&= l-\dim(\ker(A^TA)) \\
&= l-\dim(\ker(A)) \\
&= r \\
&= \dim(\operatorname{Im}(A^T)).
\end{aligned}
$$

Since $\operatorname{Im}(A^TA)\subseteq\operatorname{Im}(A^T)$ and the two spaces have the same dimension,

$$
\operatorname{Im}(A^TA)=\operatorname{Im}(A^T).
$$

Recall that $\operatorname{Im}(A)$ is the image of a linear map, also called its range or column space:

$$
\operatorname{Im}(A)=\{Ax:x\in\mathbb{R}^l\}.
$$

Moreover, _by the spectral decomposition:_

$$
A^TA=V\Lambda V^T,
$$

where $V$ is orthogonal and

$$
\lambda_1,\ldots,\lambda_r>0,
\qquad
\lambda_{r+1}=\cdots=\lambda_l=0.
$$

Therefore we have:

$$
\operatorname{Im}(A^T)=\operatorname{Im}(A^TA)
=\operatorname{span}(v_1,\ldots,v_r),
$$

where $v_1,\ldots,v_r$ are the first $r$ columns of $V$, corresponding to the positive eigenvalues. In particular, for some coefficients $a_i$, we have:
$$
A^Ty=\sum_{i=1}^r a_i v_i
$$


Denote now by $ Q_r=V\Lambda\Lambda^\dagger V^T$ the <b>orthogonal projection</b> onto $\operatorname{span}(v_1,\ldots,v_r)$. Consequently,

$$
\begin{aligned}
A^TA\hat\beta
&=A^TA(A^TA)^\dagger A^Ty \\
&=V\Lambda\Lambda^\dagger V^T A^Ty \\
&=Q_rA^Ty \\
&=A^Ty,
\end{aligned}
$$

because $A^Ty$ already belongs to $\operatorname{span}(v_1,\ldots,v_r)$. Thus, $\hat\beta$ satisfies the normal equation.

We now prove that $\hat\beta$ is the solution with the smallest $\|\cdot\|_2$-norm.
<br/>Since $ \hat\beta=(A^TA)^\dagger A^Ty=V\Lambda^\dagger V^T A^Ty, $ we have the following:

$$
\hat\beta\in\operatorname{span}(v_1,\ldots,v_r).
$$

Since $A^T A$ is singular, there are other solutions, and any other solution can be written as $\hat\beta+b$. Since both $\hat\beta+b$ and $\hat\beta$ satisfy the normal equation,

$$
A^TA(\hat\beta+b)=A^Ty=A^TA\hat\beta.
$$

Subtracting gives $ A^TAb=0 $, so we have:

$$
b\in\ker(A^TA)=\operatorname{span}(v_{r+1},\ldots,v_l).
$$

So $b$ is orthogonal to $\hat\beta$, by the Pythagorean theorem,

$$
\|\hat\beta+b\|_2^2
=\|\hat\beta\|_2^2+\|b\|_2^2
\geq \|\hat\beta\|_2^2.
$$

Therefore, $\hat\beta$ is the solution of the normal equation with the smallest Euclidean norm.

<b>Singular Value Decomposition (SVD)</b>

<b>Theorem</b>

Let $A$ be an $m \times l$ matrix of rank $r \leq \min\{m,l\}$. Then all of the following hold:
- there exists an <b>orthonormal basis</b> $v_1,\ldots,v_l$ of $\mathbb{R}^l$ consisting of eigenvectors of $A^T A$ with eigenvalues $\lambda_1 \geq \cdots \geq \lambda_r > 0$ and $\lambda_{r+1}=\cdots=\lambda_l=0$ _(the eigenvalues corresponding to the independent directions are positive, while the others are zero)_;
- for $i=1,\ldots,r$, $Av_i$ is an eigenvector of $AA^T$ with eigenvalue $\lambda_i$;
- $\mu_i=\lambda_i^{-1/2}Av_i$ are <b>orthonormal eigenvectors</b> of $AA^T$ with eigenvalues $\lambda_i$;
- $A=\sum_{i=1}^r\sigma_i\mu_i v_i^T$ with $\sigma_i=\sqrt{\lambda_i}$ _(this is the SVD of $A$)_;
- the pseudoinverse of $A$ is given by $A^\dagger=\sum_{i=1}^r\sigma_i^{-1}v_i\mu_i^T$;
- in particular, for all $y\in\mathbb{R}^m$, $\hat\beta=A^\dagger y\in\mathbb{R}^l$ is the minimizer of $\|Ab-y\|_2$ with the minimal $\|\cdot\|_2$ norm.

_The proof is left to the reader... or to the Giacomo of the future with some more time!_

<b>Corollary</b>

Let $A$ be an $m \times l$ matrix of rank $r \leq \min(m,l)$. <br/>Then $A$ has a <b>singular value decomposition</b> of the form

$$
A=U\Sigma V^T, \qquad A^\dagger=V\Sigma^\dagger U^T.
$$

- $U$ is an orthogonal $m \times m$ matrix;
- $V$ is an orthogonal $l \times l$ matrix;
- $\Sigma$ and $\Sigma^\dagger$ are diagonal $m \times l$ and $l \times m$ matrices, respectively, of the forms:

$$
\Sigma =
\begin{pmatrix}
\sigma_1 & 0 & \cdots & \cdots & 0 \\
0 & \sigma_2 & \cdots & \cdots & \vdots \\
\vdots & \vdots & \ddots & & \vdots \\
\vdots & \vdots & & \sigma_r & \vdots \\
0 & \cdots & \cdots & \cdots & 0
\end{pmatrix},
\qquad
\Sigma^\dagger =
\begin{pmatrix}
\sigma_1^{-1} & 0 & \cdots & \cdots & 0 \\
0 & \sigma_2^{-1} & \cdots & \cdots & \vdots \\
\vdots & \vdots & \ddots & & \vdots \\
\vdots & \vdots & & \sigma_r^{-1} & \vdots \\
0 & \cdots & \cdots & \cdots & 0
\end{pmatrix}.
$$

For $\sigma_i = \sqrt{\lambda_i}$, where $\lambda_i$ are the positive eigenvalues of $A^T A$.

<b>Regularization by Truncating the Pseudoinverse</b>

If the design matrix $A$ _(recall: composed of $1, x_{11}, \ldots, x_{1d}, \ldots, x_{m1}, \ldots, x_{md}$, with $m$ observations and $d$ features)_ has <b>small positive singular values</b>:

- $\hat{\beta} = A^\dagger y = A^\dagger(A\beta + \epsilon)$ is <b>sensitive to the noise</b> $\epsilon = (\epsilon_1, \ldots, \epsilon_m)$
- the numerical computation of $A^\dagger = \sum_{i=1}^r \sigma_i^{-1}v_i u_i^T$ becomes unstable (the pseudoinverse contains the term $\sigma_i^{-1}$, so if the singular value $\sigma_i$ is small, the noise component in that direction is multiplied by the large factor $1/\sigma_i$).

In this case, we can define a <b>threshold</b> $c > 0$ and define the <b>truncated SVD</b> $A_c$ and the <b>truncated pseudoinverse</b> $A_c^\dagger$ as:

$$
A_c = \sum_{i=1}^r \sigma_i \mathbf{1}_{\{\sigma_i > c\}}u_i v_i^T = \sum_{i=1}^k \sigma_i u_i v_i^T, \qquad k = \#\{i : \sigma_i > c\}.
$$

$$
A_c^\dagger = \sum_{i=1}^k \sigma_i^{-1}v_i u_i^T.
$$

Conditioned on $X_{ij}=x_{ij}$, we can also define $\hat{\beta}_c$ as:

$$
\hat{\beta}_c = A_c^\dagger y = A_c^\dagger A\beta + A_c^\dagger\epsilon
= Q_k\beta + \sum_{i=1}^k \sigma_i^{-1}v_i u_i^T\epsilon.
$$

_Intuition: $Q_k\beta$ is the signal that survives the truncation, and $A_c^\dagger$ is the amplified noise._

We can consider $c$ as a <b>threshold hyperparameter</b> that balances bias and variance. Indeed, for an increasing $c$:
- the bias of $\hat{\beta}_c$, $Q_k\beta-\beta$, increases because $Q_k\beta$ contains less information
- the Frobenius norm of the covariance matrix decreases because more $\sigma_i^{-1}$ terms are removed _(recall that the Frobenius norm is defined as $\|M\|_F = \sqrt{\sum_{i=1}^{p}\sum_{j=1}^{q} m_{ij}^2} = \sqrt{\operatorname{tr}(M^T M)}$)._

<b>Ridge Regression</b>

As briefly mentioned in the introduction chapter, we can introduce a penalty term to force the estimate $\hat\beta$ to have a small Euclidean norm. That is, we can solve the following optimization problem for a hyperparameter $\lambda > 0$:

$$
\min_{b \in \mathbb{R}^{d+1}} \left(\|Ab-y\|_2^2 + \lambda\|b\|_2^2\right).
$$

_As always_, $b$ is a minimizer if and only if:

$$
\nabla_b\left(\|Ab-y\|_2^2 + \lambda\|b\|_2^2\right)=0
\iff A^T A b - A^T y + \lambda b = 0
\iff (A^T A + \lambda I_l)b = A^T y.
$$

If we solve for $b$, we obtain the following solution $\hat\beta_\lambda$:

$$
\hat\beta_\lambda = (A^T A + \lambda I_l)^{-1}A^T y
= \sum_{i=1}^r \frac{\sigma_i}{\lambda_i+\lambda}v_i u_i^T y,
$$
where $\lambda_i=\sigma_i^2$ are the positive eigenvalues of $A^T A$.

Conditioned on $X_{ij}=x_{ij}$, we obtain:

$$
\hat\beta_\lambda
= \sum_{i=1}^r \frac{\lambda_i}{\lambda_i+\lambda}v_i v_i^T\beta
+ \sum_{i=1}^r \frac{\sigma_i}{\lambda_i+\lambda}v_i u_i^T\epsilon
\sim \mathcal{N}_{d+1}\left(
\sum_{i=1}^r \frac{\lambda_i}{\lambda_i+\lambda}v_i v_i^T\beta,
\sigma^2\sum_{i=1}^r \frac{\lambda_i}{(\lambda_i+\lambda)^2}v_i v_i^T
\right).
$$

We clearly see that, _for an increasing $\lambda$:_
- the bias of $\hat\beta_\lambda$, $\sum_{i=1}^r \frac{\lambda_i}{\lambda_i+\lambda}v_i v_i^T\beta - \beta$, increases;
- the Frobenius norm of the covariance matrix decreases.

_Generally speaking_, we do not penalize the intercept in ridge regression, since it represents the baseline of the response, so we exclude it from the penalty. The optimization problem therefore becomes, for a hyperparameter $\lambda > 0$:

$$
\min_{b \in \mathbb{R}^{d+1}} \left\{\|Ab-y\|_2^2 + \lambda \sum_{j=1}^d b_j^2\right\}.
$$


---
<br/>
<b>LASSO (Least Absolute Shrinkage and Selection Operator)</b>

_Again,_ as mentioned in the introductory chapter, we can introduce a penalty term to force $\hat\beta$ to have a small $\ell^1$-norm; i.e., we can solve the following optimization problem for a hyperparameter $\lambda > 0$:

$$
\min_{b \in \mathbb{R}^{d+1}} \left\{\|Ab-y\|_2^2 + \lambda \sum_{j=1}^d |b_j|\right\}.
$$

Note that this is a <b>non-smooth convex</b> optimization problem, _i.e. the absolute-value function has a kink (the derivative does not exist) at zero and is convex but not differentiable there._

For this reason, the $\ell^1$-penalty tends to shrink coefficients to zero and, _therefore,_ leads to a sparse solution $\hat\beta_\lambda$ (intuition: minimizing the sum of absolute values makes exact zeros attractive, so some coefficients can vanish entirely).

<b>Variable Standardization</b>

Consider now a solution $b = (b_0, \ldots, b_d)^T$ that solves $A^T A b = A^T y$. The first line of the vector equation gives:

$$
 m b_0 + \sum_{i=1}^m \sum_{j=1}^d x_{ij} b_j = \sum_{i=1}^m y_i
 \implies b_0 = \bar y - \sum_{j=1}^d \bar x_j b_j.
$$

Here, $\bar y$ and $\bar x_j$ denote the sample averages.

If we consider the case $\bar x_1 = \cdots = \bar x_d = \bar y = 0$, then $b_0 = 0$, so the first column of 1s in $A$ _(recall that the design matrix has a first column full of 1s)_ is <b>redundant!</b>

To avoid this, we can standardize the variables $x$ and $y$; _i.e. we can transform them as follows:_

$$
\tilde x_{ij} = \frac{x_{ij} - \bar x_j}{s_j},
\qquad
\tilde y_i = \frac{y_i - \bar y}{s_y}.
$$

Here,
$$
s_j^2 = \frac{1}{m} \sum_{i=1}^m (x_{ij} - \bar x_j)^2,
\qquad
s_y^2 = \frac{1}{m} \sum_{i=1}^m (y_i - \bar y)^2.
$$

Therefore, we can proceed with <b>standardized linear regression</b>, i.e. solving the following optimization problem:

$$
\min_{b \in \mathbb{R}^d} \lVert \tilde A b - \tilde y \rVert_2^2.
$$

Once we find a minimizer $\hat\beta$ for this problem, the prediction for a new data point $x = (x_1, \ldots, x_d)$ is

$$
\frac{\hat y - \bar y}{s_y}
= \sum_{j=1}^d \frac{x_j - \bar x_j}{s_j} \hat\beta_j
\implies
\hat y = s_y \sum_{j=1}^d \frac{x_j - \bar x_j}{s_j} \hat\beta_j + \bar y.
$$

_Generally speaking,_ <b>standardization is unnecessary</b>
- for OLS without regularization
- when the original units are meaningful and we want interpretable coefficients

Furthermore, <b>standardizing the input variables</b> is useful:
- in regularized regression _(e.g. truncated SVD, ridge, LASSO, and elastic net) because penalties depend on the magnitude of the coefficients
- for comparing coefficient sizes, since standardization makes them easier to compare across different scenarios/input variables

Secondly, <b>standardizing both the input and the target variables</b> is useful:
- if we want standardized regression coefficients
- if we are comparing models across targets with different scales
- in this case, the intercept is not optimized _(since it is zero from standardization of $x,y$)_, so the regularization does not penalize the intercept _(since it estimates only the coefficients)_.

<b>Cross validation</b>

Cross-validation refers to a family of <b>model validation methods</b> for assessing how a trained model generalizes to unseen data. One particular cross-validation method is called <b>k-fold cross-validation</b>, and it consists of:
- randomly partitioning the data into $k$ subgroups
- retaining a single subgroup as <b>validation data</b> and using the remaining $k-1$ subgroups to train the model
- repeating the process $k$ times and calculating the empirical loss each time
- using the <b>average validation loss</b> over $k$ groups as an estimate of the <b>generalization error</b>

Note that this method can be used to find the <b>optimal regularization parameters</b> _(e.g. the threshold $c$ or the hyperparameters in LASSO and ridge regression)_ by picking the regularization parameters that yield the <b>smallest average validation loss</b>.
<br/>In this case, if cross-validation is used to find hyperparameters, the resulting prediction function should be tested and evaluated on an _independent test dataset_.

<b>One-hot and Dummy Encoding</b>

Suppose categorical data take values in $\{1,\ldots,k\}$, but the natural order does _not_ have any meaning. <br/>If there are only two categories, such as A and B, they can be encoded with 0 and 1 easily. <br/>However, things get a bit more complicated when $k \geq 3$, i.e. when we have more values available. In this case, we have the following alternatives:
- <b>One-hot encoding</b>: if $k \geq 3$, it can be embedded in $\mathbb{R}^k$ via:

$1 \mapsto (1,0,\ldots,0), \quad 2 \mapsto (0,1,\ldots,0), \quad k \mapsto (0,0,\ldots,1)$

- <b>Dummy encoding</b>: if $k \geq 3$, it can alternatively be embedded in $\mathbb{R}^{k-1}$ via:

$1 \mapsto (0,\ldots,0), \quad 2 \mapsto (1,0,\ldots,0), \quad k \mapsto (0,0,\ldots,1)$

_(note the position of the 1s in the vector!)_

- <b>Random embeddings</b>: sometimes $\{1,\ldots,k\}$ can be embedded in $\mathbb{R}^q$ for $q \leq k$ with alternative approaches.

- impute the missing data by:

## <a id="3"><b>3 Gradient Descent</b></a>

<div align = "center">
![Bias variance tradeoff](/images/notes/third-semester/gradient-descent.png)
</div>

Imagine you are lost on a foggy mountain and you have to reach the lowest valley point _(i.e. you have to come back to the parking lot after your hike)_.<br/>Since you cannot see anything, by carefully analyzing and feeling the slope of the terrain under your feet, you find the direction that goes downhill more steeply... this could be a nice starting point to understand gradient descent, but now, let's deep dive into the technicalities!

<b>The Grid Method</b>

Suppose we have a function h we want to minimize and suppose $h : [0,1]^d \to \mathbb{R} $ is a <b>L-Lipschitz</b> function, i.e. for some constants $L \geq 0$:

$$
| h(x) - h(y) | \leq L \| x - y \|_2
$$

We try now to minimize h with the Grid Method:
- we evaluate h at the $(n + 1)^d$ grid points $(i_1/n, \ldots, i_d/n)$
- we solve $\min_{0 \leq i_1,\ldots,i_d \leq n} h(i_1/n,\ldots,i_d/n)$, i.e. we choose the smallest value
- we now want to compare $\bar x$ with the true minimizer $x^*$; to do that, denote by $\bar x$ the grid point closest to $x^* \in [0,1]^d$
- so we have: $\| \bar x - x^* \|_2 \leq \sqrt{d}/2n$
- if we apply the Lipschitz condition, because h is L-Lipschitz, we have

$$
\min_{0 \leq i_1,\ldots,i_d \leq n} h(i_1/n,\ldots,i_d/n) \leq h(\bar x) \leq h(x^*) + \frac{L\sqrt{d}}{2n}
$$

This tells us how much worse the grid solution can be than the optimum solution $x^*$.

Note that, if we want an <b>accuracy</b> of $\epsilon > 0$, we need:

$$
\frac{L \sqrt{d}}{2n} \leq \epsilon \implies n \geq \frac{L \sqrt{d}}{2\epsilon}
$$

so we need
$(\lceil\frac{L \sqrt{d}}{2 \epsilon}\rceil + 1)^d$ function evaluations... and this, _of course_, is <b>infeasible</b> in high dimension $d$ _(we call this problem the curse of dimensionality!)_

---
<br/>

<b>Convex Function</b>

We now consider much nicer functions... i.e. <b>convex functions!</b><br/>
Recall that a function $h : \mathbb{R}^d \to \mathbb{R}$ is <b>convex</b> if, for all $x,y \in \mathbb{R}^d$ and $\lambda \in (0,1)$:

$$
h(\lambda x + (1 - \lambda)y ) \leq \lambda h(x) + (1 - \lambda)h(y)
$$

_Classical 2D intuition: if you take two points $x,y$, the point $\lambda x + (1 - \lambda)y$ lies on the segment between them. The convexity condition says that the function value at this intermediate point is $\leq$ the straight line joining $h(x)$ and $h(y)$._

Recall also that every norm $\|\cdot\|$ is a <b>convex function</b>.

We define now the <b>subgradient</b> of h at $x \in \mathbb{R}^d$ as the vector $g \in \mathbb{R}^d$ such that:

$$
h(x + y) \geq h(x) + \langle y, g\rangle
$$


_Note that the symbol $\langle y, g\rangle$ represents the dot product. Recall also that, from a geometric point of view, $h(x) + \langle g, y\rangle$ represents the plane touching the graph of $h$ at $x$. The inequality says that the plane always lies before the graph of $h$._

We now define the <b>subdifferential</b> $\partial h(x)$ as the set of all subgradients of h at x.

If h is convex, $\partial h(x)$ is, for all $x \in \mathbb{R}^d$, a <b>non-empty</b> subset of $\mathbb{R}^d$.

To prove that, we fix $x \in \mathbb{R}^d$. Its epigraph is then convex:

$$
\operatorname{epi}(h) = \{(z,t) \in \mathbb{R}^{d+1} : t \geq h(z)\}.
$$

Furthermore, the point $(x, h(x))$ lies on the boundary, so the supporting hyperplane theorem says that there are $(a,b) \neq 0$ such that:

$$
a^T(z-x) + b(t-h(x)) \geq 0 \qquad \forall (z,t) \in \operatorname{epi}(h).
$$

Since the epigraph extends upward, $b > 0$, so we can set $g = -a/b$ and, taking $t = h(z)$, we get:

$$
h(z) \geq h(x) + g^T(z-x) \qquad \forall z.
$$

Therefore, $g \in \partial h(x)$ and so we can conclude that $\partial h(x) \neq \emptyset$.

Furthermore _(and most importantly)_, if a convex function $h : \mathbb{R}^d \to \mathbb{R}$ is <b>differentiable</b> at x, then $\partial h(x)$ is a singleton and we have $\partial h(x) = \nabla h(x)$.

Furthermore, $x^* \in \mathbb{R}^d$ is a <b>minimizer for a convex function</b> $h: \mathbb{R}^d \to \mathbb{R}$ if and only if $0 \in \partial h(x^*)$.

_Recall that, given a function $h: \mathbb{R}^d \to \mathbb{R}$, the gradient is the vector of all partial derivatives: it tells how much h changes when each coordinate changes and points in the direction of the steepest increase _(therefore, $-\nabla h(x)$ points in the direction of the steepest decrease)_.

---
<br/>
<b>Gradient Descent</b>

Consider now $h: \mathbb{R}^d \to \mathbb{R}$, a convex function with a minimizer $x^*$. We apply the gradient descent method.

- First, we start with $x_0 \in \mathbb{R}^d$ (which can be deterministic, i.e., chosen with a heuristic, or random)
- we apply the gradient steps. For all $k \geq 0$ and learning rate $\eta_k$:

$$
x_{k+1} = x_k - \eta_k \nabla h(x_k)
$$

- Then, from the definition of the gradient with vector $g$ and the dot product given above, we have the following:

$$
h(x^*) - h(x_k) \geq \langle x^* - x_k, \nabla h(x_k)\rangle
$$

- that translates into:

$$
\begin{aligned}
2\eta_k (h(x_k) - h(x^*)) &\leq 2\langle x_k - x^*, \eta_k \nabla h(x_k)\rangle \\
&= \|x_k - x^*\|_2^2 - \|x_k - x^* - \eta_k \nabla h(x_k)\|_2^2 + \eta_k^2 \|\nabla h(x_k)\|_2^2 \\
&= \|x_k - x^*\|_2^2 - \|x_{k+1} - x^*\|_2^2 + \eta_k^2 \|\nabla h(x_k)\|_2^2.
\end{aligned}
$$

- Therefore, we obtain the following:

$$
\sum_{k=0}^K 2\eta_k (h(x_k)- h(x^*)) \leq \|x_0 - x^*\|_2^2 - \|x_{K+1} - x^*\|_2^2 + \sum_{k=0}^K \eta_k^2 \|\nabla h(x_k)\|_2^2
$$

Furthermore, if $\|\nabla h(x_k)\|_2 \leq L$ for all $k$, then:

$$
\min_{0 \leq k \leq K} \bigl(h(x_k) - h(x^*)\bigr) \leq \frac{\sum_{k=0}^K \eta_k (h(x_k)- h(x^*))}{\sum_{k=0}^K \eta_k} \leq \frac{\|x_0 - x^*\|_2^2 + L^2 \sum_{k=0}^K \eta_k^2}{2 \sum_{k=0}^K \eta_k}
$$

So if $\sum_{k=0}^\infty \eta_k^2 < \infty$ and $\sum_{k=0}^\infty \eta_k = \infty$, then $\min_{0 \leq k \leq K} h(x_k) \to h(x^*)$ for $K \to \infty$ _(or, in other words, the minimum found with gradient descent converges to the true minimizer)_. <br/>_(Note that the required condition for $\eta_k$ can be easily satisfied, for example by setting $\eta_k = 1/(k+1)$: we have $\sum_{k=0}^\infty \frac{1}{(k+1)^2} < \infty$ and $\sum_{k=0}^\infty \frac{1}{k+1} = \infty$.)_

However, in practice, computers do not allow $K \to \infty$... so if the number of gradient steps $K$ is fixed, we choose $\eta_k$ to minimize:

$$
\frac{\|x_0 - x^*\|_2^2 + L^2 K\eta^2}{2K\eta}
$$

In this case, for an accuracy $\epsilon > 0$, we need _(and note that this does not depend on the dimension):_

$$
K \geq \left(\frac{L\|x_0 - x^*\|_2}{\epsilon}\right)^2
$$

_(Note that doubling the desired precision requires approximately four times as many gradient steps.)_

---
<br/>
<b>Stochastic Gradient Descent</b>

_Let's jump back to the foggy mountain: we are still at the top and we still need to find the parking lot. Instead of carefully testing the incline across the entire terrain before taking a step, we quickly feel the slope under one foot and immediately take a step._

Now let's introduce some technicalities: consider a probability space $(\Omega, \mathcal{F}, \mathbb{P})$ and a loss function $H$ for a <b>random observation</b> $\omega$ using the model parameters $\theta$:

$$
H : \Omega \times \mathbb{R}^d \to \mathbb{R}, \qquad (\omega, \theta) \mapsto H(\omega, \theta),
$$

where $H$ is convex in $\theta$, measurable in $\omega$, and $\mathbb{E}[|H(\omega,\theta)|] < \infty$ for all $\theta \in \mathbb{R}^d$.

The overall objective function is $h(\theta) = \mathbb{E}[H(\omega, \theta)]$, which is the <b>expected loss over all possible observations</b>.

We first state that $h(\theta) = \mathbb{E}[H(\omega,\theta)]$ is convex and that, for every measurable subgradient $\nabla H(\theta) = \nabla_\theta H(\omega, \theta)$,

$$
\nabla h(\theta) = \mathbb{E}[\nabla H(\theta)]
$$

is also a subgradient of $h$ at $\theta$.

However, $\nabla h(\theta)$ might be difficult _(or sometimes impossible)_ to compute. So we can use independent samples $H_1, H_2, \ldots$ and approximate the gradient. Technically, let $H_i$, with $i \geq 1$, be independent copies of $H$.<br/>Then fix $I \in \mathbb{N}$ and set:

$$
g_k(\theta) = \frac{1}{I} \sum_{i = kI + 1}^{(k+1)I} \nabla H_i(\theta) \approx \nabla h(\theta).
$$

For $I = 1$, we call it standard stochastic gradient descent (SGD); for $I \geq 2$, we call it SGD with mini-batches, which can reduce the variance of the gradient estimates.

_(Intuition: instead of calculating the exact gradient using all data, we estimate it from one or more randomly selected samples and use that estimate to update the parameters.)_

_Formally_, we follow these steps:
- we start at $\theta_0 \in \mathbb{R}^d$ _(that, again, can be deterministic or random, independent of $H_1, H_2, \ldots$)_
- we take the <b>stochastic gradient steps</b>, for all $k \geq 0$, with $\theta_0, \theta_1, \ldots$ random:

$$
\theta_{k+1} = \theta_k - \eta_k g_k(\theta_k)
$$

- we denote by $\mathcal{F}_k = \sigma(\theta_0, \ldots, \theta_k)$ the sigma-algebra generated by $\theta_k$ _(i.e. all the information known from the algorithm up to iteration $k$)_. Note that $\theta_k$ is $\mathcal{F}_k$-measurable; therefore, once the current parameters and past history are fixed, the stochastic gradient is an <b>unbiased estimator</b> of the true gradient. Formally, we write:

$$
\mathbb{E}[g_k(\theta_k) \mid \mathcal{F}_k] = \nabla h(\theta_k).
$$

_Intuition: SGD may take a wrong step because its gradient estimate is noisy, but, thanks to independent copies of the random loss function $H_i$ that are independent of the past, on average its direction is the same as the exact direction of non-stochastic gradient descent._

- we now assume $h$ has a minimizer $\theta^* \in \mathbb{R}^d$. Then we have:

$$
h(\theta^*) - h(\theta_k) \geq \mathbb{E}[\langle \theta^* - \theta_k, g_k(\theta_k) \rangle \mid \mathcal{F}_k],
$$

which implies

$$
\begin{aligned}
2\eta_k\bigl(h(\theta_k) - h(\theta^*)\bigr)
&\leq 2\mathbb{E}\!\left[
\left\langle \theta_k - \theta^*, \eta_k g_k(\theta_k) \right\rangle
\,\middle|\, \mathcal{F}_k
\right] \\
&= \|\theta_k-\theta^*\|_2^2
- \mathbb{E}\!\left[
\left\|
\theta_k-\theta^*-\eta_k g_k(\theta_k)
\right\|_2^2
\,\middle|\,\mathcal{F}_k
\right] \\
&\quad+ \eta_k^2\,
\mathbb{E}\!\left[
\|g_k(\theta_k)\|_2^2
\,\middle|\,\mathcal{F}_k
\right] \\
&= \|\theta_k-\theta^*\|_2^2
- \mathbb{E}\!\left[
\|\theta_{k+1}-\theta^*\|_2^2
\,\middle|\,\mathcal{F}_k
\right] \\
&\quad+ \eta_k^2\,
\mathbb{E}\!\left[
\|g_k(\theta_k)\|_2^2
\,\middle|\,\mathcal{F}_k
\right].
\end{aligned}
$$

- Again, if $\mathbb{E}[\|g_k(\theta_k)\|_2^2 \mid \mathcal{F}_k] \leq L^2$, we can write:

$$
\sum_{k=0}^{K} 2\eta_k
\mathbb{E}\!\left[h(\theta_k)-h(\theta^*)\right]
\leq
\mathbb{E}\!\left[\|\theta_0-\theta^*\|_2^2\right]
-
\mathbb{E}\!\left[\|\theta_{K+1}-\theta^*\|_2^2\right]
+
L^2\sum_{k=0}^{K}\eta_k^2.
$$

$$
\mathbb{E}\!\left[
\min_{0\leq k\leq K} h(\theta_k)
\right]
-
h(\theta^*)
\leq
\frac{
\displaystyle\sum_{k=0}^{K}
\eta_k\,
\mathbb{E}\!\left[h(\theta_k)-h(\theta^*)\right]
}{
\displaystyle\sum_{k=0}^{K}\eta_k
}
\leq
\frac{
\mathbb{E}\!\left[\|\theta_0-\theta^*\|_2^2\right]
+
L^2\displaystyle\sum_{k=0}^{K}\eta_k^2
}{
2\displaystyle\sum_{k=0}^{K}\eta_k
}.
$$

Again, if $\sum_{k=0}^\infty \eta_k^2 < \infty$ and $\sum_{k=0}^\infty \eta_k = \infty$, then $\mathbb{E}[\min_k h(\theta_k)] \to h(\theta^*)$ as $K \to \infty$.

One can also show a <b>stronger claim</b>: for a convex $h$, $\min_k h(\theta_k) \to h(\theta^*)$ almost surely as $K \to \infty$ _(and not only for its expected performance $\mathbb{E}[\cdots]$, as done before)_.

Note that SGD is also used for non-convex problems, e.g. to train neural networks, even if it is not guaranteed to converge to the global minimum.

Indeed, a convex loss function has no _"bad"_ local minima: every local minimum is also global; therefore, if SGD converges, it can reach the best possible loss $h(\theta^*)$.

Neural networks often contain flat regions, local minima, and saddle points _(critical points where the slopes in orthogonal directions are zero, but the point is not a local maximum or a local minimum)_. However, SGD is still used because it is computationally practical and often finds parameters with good predictive performance, but in theory it cannot guarantee a global minimizer _(it only reaches a stationary point)_.

<b>Validation</b>

Let $\tilde H_i$, with $i = 1, \ldots, v$, be independent copies of $H$, independent of $H_i$, and call them the <b>validation data set</b>, i.e. they have the same distribution as the training loss $H_i$ but are independent.

To validate the model, we monitor the empirical loss, defined as $\frac{1}{v}\sum_{i=1}^v \tilde H_i(\theta_k)$, on the validation dataset.

- if the validation loss stops decreasing, we <b>decrease the learning rate</b> $\eta_k$
- if the validation loss starts to increase, we stop SGD
- if a validation dataset is used in training, the resulting $\theta_k$ must still be evaluated on an independent (out-of-sample) test dataset.

_Generally speaking_, we can say that with training data we fit parameters, with validation data we choose the training settings, and with testing data we perform a final unbiased evaluation.

_Example:_ suppose we have data $(x_i, y_i)$ and we want to predict $\hat y_i = f_\theta(x_i)$.<br/>We start using the squared error loss, defined as $H_i(\theta) = (y_i - f_\theta(x_i))^2$.

We then split the data into training and validation data:
- we train on training data only, by repeatedly choosing a random mini-batch of training pairs $(x_i,y_i)$ and calculating its average loss and gradient; then we recursively update:

$$
\theta_{k+1} = \theta_k - \eta_k \frac{1}{I} \sum_{i \in \text{mini-batch}} \nabla_{\theta} (y_i - f_\theta(x_i))^2
$$

- after each epoch (i.e. a complete iteration through the entire training dataset; if we have $N$ training observations and a mini-batch contains $B$ observations, the epoch contains approximately $N/B$ gradient updates), we evaluate the current model on all the validation data and obtain:

$$
\hat h_{\mathrm{val}}(\theta_k) = \frac{1}{v} \sum_{i \in \text{validation}} (y_i - f_{\theta_k}(x_i))^2
$$

- we then store the parameter $\theta_k$ (chosen from all the epochs) that achieves the lowest validation loss.

## <a id="4"><b>4 Logistic Regression</b></a>

We first recall some basics of probability.

A random variable $Y$ is <b>Bernoulli distributed</b> with parameter $p \in [0,1]$ _(and in this case we write $Y \sim \operatorname{Ber}(p)$)_ if:

$$
\begin{cases}
\mathbb{P}[Y = 1] = p, \\
\mathbb{P}[Y = 0] = 1 - p.
\end{cases}
$$

Now we consider $Y \mid X \sim \operatorname{Ber}(p(X))$, where:
- $X = (X_1, \ldots, X_d)$
- $p(X) = \psi(\beta_0 + \beta_1 X_1 + \cdots + \beta_d X_d)$
- $\psi(x) = \frac{e^x}{e^x + 1} = \frac{1}{1 + e^{-x}}$ _(<b>logistic function</b>)_

In other words, we have:

$$
\begin{cases}
\mathbb{P}[Y = 1] = p(x), \\
\mathbb{P}[Y = 0] = 1 - p(x).
\end{cases}
$$

<div align="center">
![Logistic function](/images/notes/third-semester/logistic-function.png)
</div>

Therefore, the <b>probability mass function</b> of $Y \sim \operatorname{Ber}(p)$ is:

$$
f_p(y) =
\begin{cases}
p, & \text{if } y = 1, \\
1 - p, & \text{if } y = 0
\end{cases}
= p^y (1 - p)^{1-y}, \qquad y \in \{0,1\}.
$$

And, _following the same reasoning,_ the <b>probability mass function</b> of $m$ independent $Y_i \sim \operatorname{Ber}(p)$ _(note that they all have the same parameter $p$)_ is:

$$
\prod_{i=1}^{m} f_p(y_i) = \prod_{i=1}^{m} p^{y_i} (1 - p)^{1-y_i}.
$$

_Recall also_ that the sum of Bernoulli random variables follows a <b>binomial distribution</b>, formally:

$$
S = \sum_{i=1}^m Y_i \sim \operatorname{Binomial}(m, p).
$$

_Going further_, the <b>likelihood function</b> of $Y_1, \ldots, Y_m$ is:

$$
L(p \mid y_1, \ldots, y_m) = \prod_{i=1}^m f_p(y_i) = \prod_{i=1}^m p^{y_i}(1-p)^{1-y_i}.
$$

The <b>log-likelihood function</b> of $Y_1, \ldots, Y_m$ is:

$$
\ell(p \mid y_1, \ldots, y_m) = \log L(p \mid y_1, \ldots, y_m) = \sum_{i=1}^m \left[y_i\log(p) + (1-y_i)\log(1-p)\right].
$$

_Recall that_ the likelihood measures <b>how plausible a parameter value is</b> given the observed data, so $p$ is treated as unknown and the observations $y_1, \ldots, y_m$ are fixed. _Remember also that a larger $L(p \mid y_1, \ldots, y_m)$ implies that the proposed $p$ makes the observed sequence more likely _(maximum likelihood chooses the value of $p$ that best explains the data)_._

<b>Training and Estimation with Logistic Function</b>

We now suppose that we want to regress $Y_i \in \{0,1\}$, a <b>binary outcome</b> that follows:

$$
Y_i \mid X_i \sim \operatorname{Bernoulli}(p_i),
$$

where

$$
p_i = \psi(X_i^T b) = \frac{1}{1 + e^{-X_i^T b}}.
$$

We consider training data $(x_{i1}, \ldots, x_{id}, y_i)$, independent and identically distributed realizations of $(X_1, \ldots, X_d, Y)$.

We initially set, for $b \in \mathbb{R}^{d+1}$ and $i = 1, \ldots, m$:

$$
x_{i0} = 1, \qquad x_i^T b = \sum_{j=0}^d x_{ij}b_j, \qquad p_i(b) = \psi(x_i^T b).
$$

We define the <b>empirical loss minimization problem</b> (conditional on negative log-likelihood minimization):

$$
\begin{aligned}
&\min_{b \in \mathbb{R}^{d+1}} \sum_{i=1}^m \left\{-y_i\log(p_i(b)) + (y_i-1)\log(1-p_i(b))\right\}\\
&= \min_{b \in \mathbb{R}^{d+1}} \sum_{i=1}^m \left\{-y_i\log\bigl(\psi(x_i^T b)\bigr) + (y_i-1)\log\bigl(1-\psi(x_i^T b)\bigr)\right\} \\
&= \min_{b \in \mathbb{R}^{d+1}} \sum_{i=1}^m \left\{y_i\log\frac{1-\psi(x_i^T b)}{\psi(x_i^T b)} - \log\bigl(1-\psi(x_i^T b)\bigr)\right\} \\
&= \min_{b \in \mathbb{R}^{d+1}} \sum_{i=1}^m \left\{\log(1+e^{x_i^T b}) - y_i x_i^T b\right\}.
\end{aligned}
$$

We immediately notice that this is a <b>convex minimization problem</b> for $b \in \mathbb{R}^{d+1}$ that can be solved with (stochastic) gradient descent.

We then obtain the solution of the empirical loss minimization problem, $\hat\beta = (\hat\beta_0, \ldots, \hat\beta_d)$, and the predicted probability of $Y = 1$ given $X = (x_1, \ldots, x_d)$:

$$
\hat p(x) = \psi\left(\hat\beta_0 + \sum_{j=1}^d x_j\hat\beta_j\right).
$$

_Note that the prediction does not give the value of $Y$, but just the probability $\mathbb{P}[Y = 1]$, so we must choose a <b>decision threshold</b> $c \in (0,1)$ such that we predict $\hat y(x) = 1$ if $\hat p(x) \geq c$, and $0$ otherwise._

We now consider <b>test data</b> $(x_{i1}, \ldots, x_{id}, y_i)$, with $i = m+1, \ldots, m+n$, independent and identically distributed realizations of $(X_1, \ldots, X_d, Y)$ independent of the training data.

Then, for each case $i$, we can give the following classification:
- $P$ (positive) if $y_i = 1$
- $N$ (negative) if $y_i = 0$
- $TP$ (true positive) if $\hat y_i = 1$ and $y_i = 1$
- $FP$ (false positive) if $\hat y_i = 1$ and $y_i = 0$
- $TN$ (true negative) if $\hat y_i = 0$ and $y_i = 0$
- $FN$ (false negative) if $\hat y_i = 0$ and $y_i = 1$

We can then define <b>accuracy</b> _(i.e. the percentage of correctly predicted cases)_ as:

$$
\text{Accuracy} = \frac{TP + TN}{N + P}.
$$

However, note that when dealing with <b>imbalanced data</b>, the accuracy metric can be misleading. Indeed, if one of the two classes $P, N$ is much smaller or larger than the other, the accuracy ratio might not be the right measure since we may have very high accuracy just because we are always predicting the larger class _(and never predict the smaller class)_.

<a id="classification-metrics"></a>

Therefore, we can define other <b>performance measures</b>:

- <b>True positive rate</b> (recall, sensitivity):

$$
\text{TPR} = \frac{TP}{P}.
$$

- <b>False Positive Rate</b>

$$
\text{FPR} = \frac{FP}{N}
$$
- <b>ROC (Receiver Operating Characteristic)</b>: it shows the profile $(\text{TPR}, \text{FPR})$ for $c \in (0,1)$
- <b>AUC (Area under the curve)</b>: _larger is better_; randomly guessing produces the diagonal with AUC $= 1/2$, therefore AUC $< 1/2$ is worse than random guessing
- <b>Positive predictive value</b> (precision)

$$
\text{PPV} = \frac{TP}{TP + FP}
$$

- <b>F1 Score</b>

$$
F1 = 2 \frac{TPR \times PPV}{TPR + PPV} = \frac{2 TP }{2 TP + FP + FN}
$$

</div>

Suppose that we want to classify a good (P) and a bad borrower (N).

In this case, we may aim to minimize the FDR (the false discovery rate) or, _similarly,_ maximize the true positive rate.
<br/>Furthermore, note that in this case a small AUC is desirable, since predictions should be independent of a protected attribute.


## <a id="5"><b>5 Kernel Methods: Support Vector Machines and Reproducing Kernel Hilbert Spaces</b></a>

A support vector machine (SVM) is a method for <b>supervised learning</b> that began attracting attention in 1990. The name comes from:
- machines that turn inputs into outputs
- vectors that support decisions

We recall that supervised learning uses labeled data _(inputs with known answers)_ to learn to predict an output; it is usually used for classification and regression. _On the other hand,_ unsupervised learning uses unlabeled data _(data without known answers)_ to discover hidden patterns or structures, often for clustering, dimensionality reduction, and anomaly detection _(some common algorithms: K-means, hierarchical clustering, PCA, autoencoders, etc.)_.

In contrast to other ML methods, numerical optimization is well understood for SVMs, so they are reliable and interpretable. Furthermore, the theory behind SVMs is frequently used in the field of ML; _for example_, large neural networks can be viewed through the lens of kernel methods _(neural tangent kernels)_.

_Technically speaking_, we need to define the <b>decision hyperplane</b>.

Let $x_i = (x_{i1},\ldots,x_{id}) \in \mathbb{R}^d$ and $y_i \in \{-1,1\}$ for $i = 1,\ldots,m$, and assume that <b>linear classification is possible</b>, i.e. there exist $w \in \mathbb{R}^d$ _(weights)_ and $b \in \mathbb{R}$ _(bias)_ such that:

$$
\operatorname{sign}(\langle w,x_i\rangle + b) = y_i \quad \forall i
$$

_Intuition: the classifier defines a score $w^T x_i + b$, and the sign of the score gives the predicted class._

So each classifier $(w,b)$ specifies a decision hyperplane, _i.e. the dividing boundary between the two classes,_ where the vector $w$ controls the orientation and $b$ shifts it:

$$
H(w,b) = \{x \in \mathbb{R}^d : \langle w,x\rangle + b = 0\}
$$

_In particular,_ we want to choose a valid classifier $(w_D, b_D) \in \mathbb{R}^d \times \mathbb{R}$, normalized such that $\|w_D\|_2 = 1$, that <b>maximizes the distance</b> between the data and the decision plane. For a correctly classified point, this distance is $y_i(\langle w_D,x_i\rangle+b_D)$, so:

$$
(w_D,b_D) \in \operatorname*{argmax}_{\substack{\|w\|_2=1,\ b\in\mathbb{R}\\ y_i(\langle w,x_i\rangle+b)>0\ \forall i}}\ \min_{1\leq i\leq m} y_i(\langle w,x_i\rangle+b).
$$

_Equivalently,_ let $(w^*,b^*)$ solve the <b>hard-margin optimization problem</b>:

$$
\min_{w\in\mathbb{R}^d,\ b\in\mathbb{R}} \frac{1}{2}\|w\|_2^2
\quad\text{subject to}\quad
 y_i(\langle w,x_i\rangle+b)\geq 1,\quad i=1,\ldots,m.
$$

Then $(w_D,b_D)=(w^*/\|w^*\|_2,\ b^*/\|w^*\|_2)$.

<b>Lifting the data and slack variables</b>

With the following optimization problem, we could have two issues:
- linear separation not possible _(i.e. not all the constraints can be satisfied)_
- we may not want to satisfy all constraints to avoid overfitting

Therefore, we can do the following:
- lift $x_i$ to a _possibly infinite-dimensional_ <b>Hilbert space $\mathcal{H}$</b> with a feature map $\Phi: \mathbb{R}^d \to \mathcal{H}$ and use $w \in \mathcal{H}$ as the classifier
- introduce a slack variable $\xi_i \geq 0$, which allows the margin constraints to be relaxed in exchange for a penalty in the objective function, leading to the <b>adjusted optimization problem</b>:

$$
\begin{aligned}
\min_{w\in\mathcal{H},\ b\in\mathbb{R},\ \xi\in\mathbb{R}^m}
&\quad \frac{1}{2}\|w\|_{\mathcal{H}}^2 + C\sum_{i=1}^{m}\xi_i \\
\text{subject to}
&\quad y_i\bigl(\langle w,\Phi(x_i)\rangle_{\mathcal{H}}+b\bigr)\geq 1-\xi_i,\quad i=1,\ldots,m,\\
&\quad \xi_i\geq 0,\quad i=1,\ldots,m.
\end{aligned}
$$

_We recall that_ a <b>Hilbert space</b> is a vector space with an inner product _(i.e. a generalized dot product)_ where limits of converging sequences stay in the space. Ordinary Euclidean space $\mathbb{R}^2$ is an example, but Hilbert spaces can also have infinite dimensions.

_Intuition: the slack variable $\xi_i$ measures how far point $i$ falls short of the required margin. A positive slack can mean that the point is correctly classified but inside the margin, or that it is misclassified._

_Furthermore,_ a large C (<b>bias-variance knob</b>) means violations are expensive, so the fit is tight to the data, _on the other hand,_ a small C implies that the margin is wide, the fit is smoother and more errors are tolerated _(with higher risk of overfitting)_.

<div align = "center">
![Bias variance tradeoff](/images/notes/third-semester/svm-8.png)
</div>

- Points correctly classified on or beyond the margin have $\xi_i = 0$.
- Points correctly classified inside the margin have $0 < \xi_i < 1$.
- Points on the decision boundary have $\xi_i = 1$, and misclassified points have $\xi_i > 1$.

_Note that_ the constraints and the requirements $\xi_i \geq 0$ imply:

$$
\xi_i \geq \max\left\{0, 1-y_i\bigl(\langle w,\Phi(x_i)\rangle_{\mathcal{H}}+b\bigr)\right\}
= \ell\bigl(y_i,f_{w,b}(x_i)\bigr),
$$

where the <b>hinge loss</b> is $\ell(y,y') = \max\{0,1-yy'\}$ and $f_{w,b}(x)=\langle w,\Phi(x)\rangle_{\mathcal{H}}+b$.


At the optimum, the slack variables equal these lower bounds, so we can rewrite the optimization problem as:

$$
\min_{w\in\mathcal{H},\ b\in\mathbb{R}} \lambda\|w\|_{\mathcal{H}}^2 + \frac{1}{m}\sum_{i=1}^{m}\ell\bigl(y_i,f_{w,b}(x_i)\bigr),
\qquad \lambda = \frac{1}{2mC}.
$$

We now recall that $f_{w,b} = \langle w, \Psi(x_i)\rangle + b$, so we can use the fact that the function space $\mathcal{H} = \{f : \mathbb{R}^d \to \mathbb{R} \text{ such that } f = \langle w, \Phi(\cdot)\rangle \text{ for some } w \in \mathcal{H}\}$ is itself a <b>Hilbert space</b> with norm:

$$
\|f\|_{\mathcal H}=\min\{\|w\|_{\mathcal H}: f=\langle w,\Phi(\cdot)\rangle_{\mathcal H}\}.
$$

so the optimization problem becomes:

$$
\min_{f,b}\frac{1}{m}\sum_{i=1}^{m}\ell(f(x_i)+b,y_i)+\lambda\|f\|_{\mathcal H}^2.
$$

_Intuition: we stop optimizing over weights and optimize over functions._ Until now, the unknown was the vector $w\in\mathcal H$ and the classifier was $f(x)=\langle w,\Phi(x)\rangle+b$. But, _in general_, we care about $f$, not about $w$, so we parametrize the problem in terms of $f$ by considering that each $w$ gives a function.<br/>Therefore, we can talk in terms of a space of functions that, _in this case,_ is called the <b>reproducing kernel Hilbert space (RKHS)</b> associated with its feature map.

<b>Support Vector Regression (SVR)</b>

_We initially recall that_ in regression we want to find a function f(x) that predicts a continuous y. However, OLS <b>penalizes every error</b>. _In contrast,_ SVR takes a different approach and penalizes only errors bigger than a threshold (later denoted by $\epsilon$) and looks for a function that is as simple (flat) as possible.

In particular, the goal of SVR is to find a hyperplane $(w, b) \in \mathcal{H} \times \mathbb{R}$ that best approximates the relationship between the <b>lifted inputs $\Phi(x)$</b> in $\mathcal{H}$ _(the feature map)_ and the <b>continuous output</b> $y \in \mathbb{R}$.

In this setting, we also notice that the model is not linear in the original space, but this becomes linear in the lifted space, as $f(x) + b = \langle w, \Psi(x)\rangle + b$.

<b>Tube-SVR</b> looks for a hyperplane that keeps the predictions in an $\epsilon$-wide tube around the fitted function. Deviations inside the tube ($|y_i - \langle w, \Psi(x_i)\rangle - b| \leq \epsilon$) do not bring any penalty, but deviations outside the tube are penalized in proportion to their distance from the boundary.

The optimization problem for Tube-SVR, assuming $\epsilon \geq 0$ is fixed and represents the $\epsilon$-tube in which prediction errors incur no penalty and/or the noise the model tolerates, is:

$$
\min_{w,b,\xi\in\mathcal H\times\mathbb R\times\mathbb R^m}
\|w\|_{\mathcal H}^2+C\sum_{i=1}^{m}\xi_i
$$
subject to
$$
|y_i-\langle w,\Phi(x_i)\rangle_{\mathcal H}-b|
\leq\epsilon+\xi_i,\qquad \xi_i\geq 0.
$$

where $\langle w,w\rangle_{\mathcal H}=\|w\|_{\mathcal H}^2$ is the <b>regularizer</b>, since small $\|w\|_{\mathcal H}$ implies a flat and smooth function that is less sensitive to input changes and therefore less prone to overfitting _(same role as the margin term in the SVM)_. $\xi_i$ are the <b>slack variables</b> and they measure how far each point falls outside the tube. Then, the term $C\sum_{i=1}^{m}\xi_i$ penalizes the total slack _(again: with large C, errors are expensive, so the model fits tightly, increasing the risk of overfitting)_.

_Similarly_ to classification, if we substitute the optimal slack $\xi_i = \max\{0, |y_i - f(x_i)-b|-\epsilon\}$, we can rewrite the optimization problem in $\mathcal H = \{f : f = \langle w, \Phi(\cdot)\rangle \text{ for some } w\in\mathcal H\}$ as:

$$
\min_{f\in\mathcal H,\ b\in\mathbb R}
\frac{1}{m}\sum_{i=1}^{m}\ell_\epsilon(f(x_i)+b,y_i)
+\lambda\|f\|_{\mathcal H}^2.
$$

where $\ell_\epsilon$ is now the $\epsilon$-insensitive loss function, defined as $\ell_\epsilon(y,y')=\max\{0,|y-y'|-\epsilon\}$, which is "insensitive" since it produces zero loss for errors smaller than $\epsilon$.

Note that the _user-friendly_ square loss $\ell(y,y')=(y-y')^2$ is a very popular choice for SVR.

<b>Kernel Functions and Reproducing Kernel Hilbert Spaces</b>
The previous discussion was _veeeeery_ theoretical in the following ways:
- what is a good feature map \Psi(x)?
- how should we choose the Hilbert space?
- what is the resulting function space H?

The <b>kernel trick</b> makes it possible to work directly with a <b>kernel function</b> without explicitly using $\Psi$, $\mathcal H$, and the feature map.

<b>Definition: Kernel</b>

Let $\mathcal X$ be a non-empty set. A function $k:\mathcal X\times\mathcal X\to\mathbb R$ is called a kernel on $\mathcal X$ if there exists a Hilbert space $\mathcal H$ and a map $\Psi:\mathcal X\to\mathcal H$ such that:

$$
k(x,x')=\langle\Psi(x),\Psi(x')\rangle
\qquad\forall x,x'\in\mathcal X.
$$

_Intuition:_ a kernel is a function that takes two points and returns a number. That number is an inner product taken in some other space. <br/>In particular, the raw inputs from the set $\mathcal X$ can be anything _(vectors, text, graphs, etc.)_; there's a feature map $\Psi:\mathcal X\to\mathcal H$ that maps each input into a Hilbert space $\mathcal H$ where an inner product is defined.

_Note that "kernel" terminology is totally unrelated to the kernel in linear algebra!_

<b>Lemma (necessary and sufficient condition to be a kernel)</b>

A function $k:\mathcal X\times\mathcal X\to\mathbb R$ is a kernel if and only if it is <b>symmetric and positive semidefinite</b>, i.e.

$$
\sum_{i=1}^{n}\sum_{j=1}^{n}a_i a_j k(x_i,x_j)\geq 0
\qquad\text{for all }n,\ x_1,\ldots,x_n\in\mathcal X,\ a_1,\ldots,a_n\in\mathbb R.
$$

We now provide some examples of kernel functions on R^d:
- <b>linear kernel</b> $k(x,x')=\langle x,x'\rangle$
- <b>polynomial kernel</b> $k(x,x')=(\langle x,x'\rangle+c)^p$ for all $p\in\mathbb N$ and $c\in\mathbb R_+$
- <b>Gaussian kernel</b> $k(x,x')=\exp(-\|x-x'\|_2^2/\gamma^2)$ for all $\gamma>0$
- <b>compactly supported radial basis kernel</b> $k(x,x')=\max\{1-\|x-x'\|_2,0\}^p$ for $p>d/2$

_In general,_ kernels of the form $k(x,x')=\Psi(\|x-x'\|_2)$ for $\Psi:\mathbb R_+\to\mathbb R$ are called <b>radial basis function kernels</b>. _Moreover,_ a scaling factor $\gamma$ such that $k_\gamma(x,x')=\Psi(\|x-x'\|_2/\gamma)$ is called the <b>bandwidth</b>.

<br/>
<b>Reproducing Kernel Hilbert Spaces</b>

Let $\mathcal{H}$ be a Hilbert space of functions $f: \mathcal{X} \to \mathbb{R}$. Then $\mathcal{H}$ is a <b>reproducing kernel Hilbert space (RKHS)</b> if $\delta_x: \mathcal{H} \to \mathbb{R}$, given by $\delta_x(f) = f(x)$, is <b>continuous</b> for all $x \in \mathcal{X}$.

Furthermore, a function $k: \mathcal{X} \times \mathcal{X} \to \mathbb{R}$ is a <b>reproducing kernel</b> of $\mathcal{H}$ if:
- it is a member of the space: $k(x, \cdot) \in \mathcal{H}$ for all $x \in \mathcal{X}$
- it satisfies the <b>reproducing property</b>: $f(x) = \langle f, k(x, \cdot)\rangle$ for all $f \in \mathcal{H}$ and $x \in \mathcal{X}$

If this function $k$ exists, we call $\Psi: \mathcal{X} \to \mathcal{H}$, given by $\Psi(x) = k(x, \cdot)$, the <b>canonical feature map</b>.

_Intuition: an RKHS is a space of functions where evaluating a function at a point is a <b>well behaved operation</b>, i.e. for each fixed x, f(x) cannot change while the function norms stays norm.<br/> _As a consequence,_ we have the reproducibility property: we can recover a function value at x by taking an inner product with a special function associated with x.

_So,_ an RKHS is a function space with a norm and inner product that make pointwise evaluation possible through a kernel.

<b>Theorem (Reproducing Kernel Hilbert Spaces)</b>
- If $\mathcal{H}$ has a reproducing kernel $k$, then $\mathcal{H}$ is an RKHS
- every RKHS has a unique reproducing kernel $k$
- for every kernel $k$, there exists a unique RKHS having $k$ as its reproducing kernel.

<b>RKHS Learning: the Kernel Trick</b>

Let $\mathcal{X}$ be a non-empty set. For given data $(x_1, y_1), \ldots, (x_m, y_m) \in \mathcal{X} \times \mathbb{R}$, we want to solve the learning problem over an RKHS $\mathcal{H}$:

$\displaystyle \min_{f \in \mathcal{H}} \frac{1}{m} \sum_{i=1}^{m} \ell(f(x_i), y_i) + \lambda \|f\|_{\mathcal{H}}^2$

<b>Representer Theorem</b>

Let $\ell: \mathbb{R} \times \mathbb{R} \to [0, +\infty]$ be a continuous function in its first argument, and let $\mathcal{H}$ be the RKHS of a kernel $k: \mathcal{X} \times \mathcal{X} \to \mathbb{R}$. Then there is a minimizer $f_m^* \in \mathcal{H}$ of $\inf_{f \in \mathcal{H}} \frac{1}{m} \sum_{i=1}^{m} \ell(f(x_i), y_i) + \lambda \|f\|_{\mathcal{H}}^2$.

This minimizer is of the form, for some $a_1, \ldots, a_m \in \mathbb{R}$:

$f_m^*(x) = \sum_{i=1}^{m} a_i k(x_i, x)$

_Moreover,_ if $\ell$ is convex in its first argument, $f_m^*$ is unique.

_Intuition:_ we can search over every function in a possibly infinite-dimensional space $\mathcal{H}$, but the optimal function can be written only using the training examples as defined above. Each function $k(x_i,\cdot)$ is a kernel centered at a training input, and the coefficients $a_i$ are the weights. Therefore, we can solve the learning problem using just kernel evaluations between data points.

Furthermore, we also have the following theorem:

<b>Representer Theorem with Intercept</b>

Let $\ell:\mathbb R\times\mathbb R\to[0,\infty]$ be a continuous function in its first argument and $\mathcal H$ the RKHS of a kernel $k:\mathcal X\times\mathcal X\to\mathbb R$. Then, if $\inf_{f\in\mathcal H}\frac{1}{m}\sum_{i=1}^{m}\ell(f(x_i),y_i)+\lambda\|f\|_{\mathcal H}^2$ has a solution, it is of the form $(f_m^*,b_m^*)$ where:

$f_m^*(x) = \sum_{i=1}^{m} a_i k(x_i,x)$

<b>Corollary (Kernel Ridge Regression)</b>

Let $\mathcal{H}$ be the RKHS of a kernel $k$. The <b>kernel ridge regression problem</b>

$$
\inf_{f \in \mathcal{H}} \frac{1}{m} \sum_{i=1}^{m} (f(x_i) - y_i)^2 + \lambda \|f\|_{\mathcal{H}}^2
$$

has a unique solution given by

$$
f_m^*(x) = \sum_{i=1}^{m} a_i k(x_i, x),
\qquad
a = (K_m + \lambda m I_m)^{-1} y,
$$

where $K_m \in \mathbb{R}^{m \times m}$ is given by $K_m[i,j] = k(x_i, x_j)$, $I_m$ is the identity matrix, and $y = (y_1, \ldots, y_m)^T$.

<b>Corollary (Kernel Ridge Regression with Intercept)</b>

Let $\mathcal{H}$ be the RKHS of a kernel $k$. The <b>kernel ridge regression problem with an intercept</b>

$$
\inf_{f \in \mathcal{H},\ b \in \mathbb{R}} \frac{1}{m} \sum_{i=1}^{m} (f(x_i) + b - y_i)^2 + \lambda \|f\|_{\mathcal{H}}^2
$$

has a unique solution $(f_m^*, b_m^*)$, where

$$
b_m^* = \frac{\mathbf{1}_m^T (K_m + \lambda m I_m)^{-1} y}{\mathbf{1}_m^T (K_m + \lambda m I_m)^{-1} \mathbf{1}_m},
\qquad
f_m^*(x) = \sum_{i=1}^{m} a_i k(x_i, x),
$$

$$
a = (\lambda m I_m + K_m)^{-1}(y - b_m^* \mathbf{1}_m).
$$

<b>Numerical Methods</b>

We start by noticing that the <b>square loss</b> admits closed-form solutions, so common implementations include the <b>scikit-learn package</b> in Python _(sklearn.kernel_ridge.KernelRidge)_. This is computationally efficient, but memory requirements are <b>quadratic in the dataset</b>, and usually the coefficients are nonzero _(no sparsity)_.

```python

from sklearn.kernel_ridge import KernelRidge
from sklearn.metrics import mean_squared_error
from sklearn.model_selection import train_test_split

# A small nonlinear dataset
rng = np.random.default_rng(42)
X = np.linspace(-3, 3, 120).reshape(-1, 1)
y = np.sin(X[:, 0]) + rng.normal(0, 0.1, size=len(X))

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)

model = KernelRidge(kernel="rbf", alpha=0.1, gamma=0.5)
model.fit(X_train, y_train)

predictions = model.predict(X_test)

```

For <b>binary classification with the hinge loss</b>, $\ell(y,y') = \max\{0, 1 - yy'\}$, the <b>Sequential Minimal Optimization (SMO)</b> algorithm is usually used. SMO is a form of coordinate descent, where, at each step, two indices $(i_1, i_2)$ are chosen and we optimize only over $(a_{i_1}, a_{i_2})$. _Generally speaking,_ SMO belongs to a class of algorithms that are based on solving <b>simpler sub-problems</b>, called decomposition methods, chunking, or subset selection.
Notice that, _for large datasets,_ many $a_i$ may simply be equal to $0$, so we have a sparse solution.
For implementing SMO, again the scikit-learn package _(sklearn.svm.SVC)_ is very common.

```python
from sklearn.datasets import make_moons
from sklearn.metrics import accuracy_score
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

X, y = make_moons(n_samples=500, noise=0.25, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)

model = make_pipeline(
    StandardScaler(),
    SVC(kernel="rbf", C=1.0, gamma="scale"),
)
model.fit(X_train, y_train)

predictions = model.predict(X_test)
svc = model[-1]
```

For the $\epsilon$-insensitive loss $\ell_\epsilon(y,y') = \max\{0, |y-y'|-\epsilon\}$, we can apply a variant of the SMO algorithm to general regression problems using the same scikit-learn package. In this case, the model treats outliers more robustly and produces a sparse solution.

_However, unlike squared-error kernel ridge regression,_ $\epsilon$-SVR doesn’t have a simple linear solution: its loss function has corners and is <b>not differentiable</b> at the band’s edges, so it uses an optimization algorithm. The problem is still convex and tractable: non-differentiability just means there’s no ordinary smooth-loss formula to solve it directly.

```python
import numpy as np
from sklearn.metrics import mean_squared_error
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVR

rng = np.random.default_rng(42)
X = np.linspace(-3, 3, 160).reshape(-1, 1)
y = np.sin(1.5 * X[:, 0]) + rng.normal(0, 0.08, size=len(X))

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)

# Simulate one unusually noisy training observation.
y_train = y_train.copy()
y_train[0] += 2.0

model = make_pipeline(
    StandardScaler(),
    SVR(kernel="rbf", C=1.0, epsilon=0.15, gamma="scale"),
)
model.fit(X_train, y_train)
predictions = model.predict(X_test)

```

<b>SMO Algorithm for Binary Classification</b>


For $\ell(y,y') = \max\{0, 1 - yy'\}$ the <b>empirical RKHS problem with intercept</b> is:

$$
\min_{\substack{a \in \mathbb{R}^m,\ \xi \in \mathbb{R}^m,\ b \in \mathbb{R}}}
\|f_a\|_{\mathcal H}^2 + C\sum_{i=1}^{m}\xi_i
$$

s.t. $y_i(f_a(x_i) + b) \ge 1 - \xi_i,\qquad \xi_i \ge 0$.

The <b>Lagrangian </b> is:

$$
\min_{a,\xi,b}\max_{\eta,w \ge 0}
\mathcal{L}
= \|f_a\|_{\mathcal H}^2
+ C\sum_{i=1}^{m}\xi_i
- \sum_{i=1}^{m}\eta_i\xi_i
- \sum_{i=1}^{m}w_i\bigl(y_i(f_a(x_i)+b)-1+\xi_i\bigr).
$$

if we apply the _First Order Conditions_ with respect to a, $\xi$ and b, we end up with the <b>dual formulation (quadratic program with box constraint)</b>:

$$
\max_{w \in [0,C]^m}
\left\{
\sum_{i=1}^{m}w_i
- \frac{1}{4}\sum_{i=1}^{m}\sum_{j=1}^{m}
w_iw_jy_iy_jk(x_i,x_j)
\right\}
\quad\text{subject to}\quad
\sum_{i=1}^{m}w_iy_i=0.
$$

_If we go back to the optimization problem,_ we notice that the objective wants to keep the boundary simple by penalizing more complex functions ($\|f_a\|_{\mathcal H}^2$) and penalizing margin violations ($C\sum_{i=1}^{m}\xi_i$). In this context, the Lagrangian attaches a $w_i$ to each margin constraint. In the dual form, the optimization works with the weights and the pairwise kernel similarities ($k(x_i,x_j)=\langle\Phi(x_i),\Phi(x_j)\rangle$) instead of directly with the optimizing function.



<b>SMO Algorithm from Platt, 1998</b>

Note that the following algorithm comes from the paper <a href="https://www.researchgate.net/publication/2624239_Sequential_Minimal_Optimization_A_Fast_Algorithm_for_Training_Support_Vector_Machines" target="_blank">Sequential Minimal Optimization: A Fast Algorithm for Training Support Vector Machines</a>, written by Platt (Google) in 1998. The idea is that, _instead of optimizing for all coefficients $w_1,\ldots,w_m$,_ the algorithm can repeatedly:
- selects two coefficients
- optimizes only over those coefficients while keeping the constraints valid
- updates the model and repeats until convergence

This comes from the fact that the dual SVM problem has _many variables_, one for each training point, so solving all of them at once can be very expensive.

_Technically speaking_:
- we initialize $w_1^{(0)} = w_2^{(0)} = \cdots = w_m^{(0)} = 0$
- we iterate $j = 1,2,\ldots$ until the convergence criterion is satisfied _(for example, if the KKT conditions are approximately satisfied)_:
    - choose indices $i_1, i_2 \in \{1,\ldots,m\}$ with $i_1 \neq i_2$ according to a given rule or heuristic
    - set $w_i^{(j)} = w_i^{(j-1)}$ for $i \notin \{i_1, i_2\}$
    - choose $(w_{i_1}^{(j)}, w_{i_2}^{(j)})$ to maximize the dual objective over the feasible values of this pair, keeping all other coefficients fixed
    - update according to the first-order conditions
- the output is the <b>optimal function</b> $f_a(x) = \frac{1}{2}\sum_{i=1}^{m} w_i^{(j)} y_i k(x_i,x) + b$, where the term $w_i y_i / 2$ follows from the first-order conditions.

<b>Numerical Approaches: Large-Scale Methods for Square Loss</b>

_Again,_ we recall that analytical solutions for the square loss are <b>not feasible for large data sets</b>. So we propose some approaches to fix this limitation.

We start with the <b>feature selection / random feature method</b>, whose basic idea is to select a subset $I \subset \{1,\ldots,m\}$, with $|I| < m$, where the selected points are called <b>landmarks (inducing points)</b>, and derive an estimator of the form:

$$
\hat f(x) = \sum_{i\in I} a_i k(x_i,x).
$$

_Intuition: many training points can be redundant, and a carefully chosen subset can represent most of the important structure in the full kernel matrix._

_Note that_ methods differ in how they choose the set $I$. For example, using the <a href="https://papers.nips.cc/paper_files/paper/2000/hash/19de10adbaa1b2ee13f77f679fa1483a-Abstract.html" target="_blank">Nyström method</a>, we choose a subset of rows and columns from the full kernel matrix by setting:
- $I$: selected landmark indices
- $C = K_{:,I}$: similarities between all points and the landmarks
- $W = K_{I,I}$: similarities among the landmarks

so we can approximate the full matrix as
$$
K \approx C W^\dagger C^T,
$$
where $W^\dagger$ is the <b>pseudoinverse</b> of $W$.


_Secondly,_ we can opt for <b>preconditioning methods</b>. A popular method is called <b>FALKON</b> and tries to find suitable $B$ and $z$ such that:

BB^T = A^-1, B^TABz = B^T

then a = B is a solution of Aa = y for A = (K_m + \lambda m I_m) is the closed form solution of the above corollary

_However,_ note that constructing $B$ precisely can be costly, so we can instead look for $B$ such that $BB^T \approx A^{-1}$ _(using again a random feature method like the Nyström approximation)_.

<b>Function approximation with RKHS</b>

<b>Definition: universal kernel</b>

Let $k:\mathcal X\times\mathcal X\to\mathbb R$ be a kernel on a topological space $\mathcal X$. We say that its RKHS $\mathcal H$ _(or, equivalently, $k$)_ is <b>universal</b> if $\mathcal H$ is dense in the set of all continuous functions $f:\mathcal X\to\mathbb R$ with respect to the sup norm, i.e. _for every continuous function_ $f:\mathcal X\to\mathbb R$ and $\epsilon>0$, there exists $h\in\mathcal H$ such that:

$$
\|f-h\|_\infty\leq\epsilon.
$$

_Intuition:_ a universal kernel is a kernel whose RKHS $\mathcal H$ is expressive enough to approximate any continuous function on the input space $\mathcal X$, where
$$
\|f-h\|_\infty=\sup_{x\in\mathcal X}|f(x)-h(x)|
$$
is the largest approximation error and $h\in\mathcal H$ is a function produced by the kernel model.

To better understand it, consider $f$ to be an arbitrary smooth curve and $h$ to be the hidden prediction function learned using the kernel. If the kernel is universal, given enough suitable kernel functions with appropriate coefficients, we can make $h$ _uniformly close_ to $f$. In this case, the RKHS may contain _infinitely many_ functions, but it does not necessarily contain $f$. _(You can think of this as analogous to polynomial approximation: polynomials may not be equal to every continuous function, but on a compact interval they can approximate every continuous function.)_

We now consider $\mathcal X$ to be a compact subset of $\mathbb R^d$; the following examples are universal kernels:
- <b>exponential kernel</b>: $k(x,x')=\exp(\gamma\langle x,x'\rangle)$ for $\gamma>0$
- <b>Gaussian kernel</b>: $k(x,x')=\exp(-\gamma\|x-x'\|_2^2)$ for $\gamma>0$
- <b>binomial kernel</b>: $k(x,x')=(1-\langle x,x'\rangle)^{-\alpha}$ for $\alpha>0$

<br/>
<b>Function approximation with RKHS: Sample efficiency</b>

 Consider a Gaussian kernel _(other smooth universal kernels would also work)_ and $\ell(y,y')=(y-y')^2$.

 <b>Theorem: Worst-Case Learning Rate for Kernel Regression</b>

 Let $\rho$ be "sufficiently smooth" and the optimal regression function $\bar f$ be $s$-times continuously differentiable. <br/>
 Let $(X_i,Y_i)_{i=1}^{\infty}$ be i.i.d. such that $(X_i,Y_i)\sim\rho$.<br/>
 Let $\hat f_m$ be the optimal kernel regression function for data $(X_i,Y_i)_{i=1}^{m}$ and $\lambda_m=m^{-d/(2s+d)}$. <br/>
 Then there exists $C>0$ such that:

 $$
 \lim_{m\to\infty}
 \mathbb P\left(
 \|\hat f_m-\bar f\|_{L^2(\rho_X)}
 \geq C m^{-s/(2s+d)}
 \right)=0.
 $$

 _Intuition:_ the error is roughly of order $m^{-s/(2s+d)}$, so the error decreases polynomially with the amount of data and the exponent determines how quickly this happens. Furthermore, the parameter $s$ describes the regularity of the true regression function _(small $s$: the function can vary sharply; large $s$: the function is smoother and easier to approximate)_, so the rate gets faster as $s$ increases. _On the other hand,_ the rate gets slower as $d$ increases _(curse of dimensionality)_.

 <b>Theorem: Minimax Lower Rates of Convergence</b>

 Let $\{\rho_\theta:\theta\in\Theta\}$ be a sufficiently rich family of smooth measures. <br/>Then, there exists $c>0$ such that:

 $$
 \lim_{m\to\infty}\inf_{\hat T_m}\sup_{\theta\in\Theta}
 \mathbb P\left(
 \|\hat T_m-\bar f_\theta\|_{L^2(\rho_X)}
 > c m^{-s/(2s+d)}
 \right)=1.
 $$

 where $\bar f_\theta$ is the optimal least-squares regression function for $\rho_\theta$.

 _Intuition:_ the previous theorem says kernel regression can achieve the specified rate; the minimax theorem says that no method can generally do better over the whole problem class. Therefore, the rate is called <b>minimax-optimal</b>.

..._To sum up, we have seen that:_
- kernel functions are <b>analytically</b> and <b>numerically</b> tractable
- under suitable smoothness and distribution assumptions, kernel regression achieves the best possible worst-case learning rate, up to constants.


However, we've also seen some problems:
- for kernel methods, the number of parameters ($a_1,\ldots,a_m$) grows with the number of data points
- the kernel must be chosen from the start and affects solution quality
- even though learning rates of kernel methods are optimal _in general_, in some specific situations other learning methods can adapt to the structure of the data better than kernel methods.



## <a id="6"><b>6 Neural Networks</b></a>

Even if now _(as of October 2026)_ we only speak about frontier-AI models driven by powerful neural networks, they are actually not new: the first models date back to the 1940s and backpropagation to the 1980s. _More specifically:_
- in 1940–1960: first mathematical models of biological neurons (<a href="https://link.springer.com/article/10.1007/BF02478259" target="_blank">McCulloch and Pitts, 1943</a>, <a href="https://doi.org/10.4324/9781410612403" target="_blank">Hebb, 1949</a>)

- from 2006 to now: the deep learning revolution, with efficient training of deep belief networks <a href="https://doi.org/10.1162/neco.2006.18.7.1527" target="_blank">(Hinton et al., 2006)</a> and efficient training of deep neural networks (<a href="https://papers.nips.cc/paper/2006/hash/5da713a690c067105aeb2fae32403405-Abstract.html" target="_blank">Bengio et al., 2006</a> and <a href="https://papers.nips.cc/paper/2006/hash/87f4d79e36d68c3031ccf6c55e9bbd39-Abstract.html" target="_blank">Ranzato et al., 2006</a>)

However, things started getting serious due to increased computational power _(which means larger networks can be trained)_ and increased data availability _(which means networks can learn well)_.

<b>Feedforward Neural Networks (FNNs)</b>

We now spend some time diving deep into the different categories of neural networks.

<div align = "center">
![Bias variance tradeoff](/images/notes/third-semester/fnns.png)
</div>

We consider an input layer $x_j$ and a <b>first hidden layer</b>, defined as:

$$
\begin{aligned}
\tilde a_i^{(1)} &= \sum_{j=1}^{N_0} W_{ij}^{(1)} x_j + b_i^{(1)}, \\
a_i^{(1)} &= \rho\left(\tilde a_i^{(1)}\right), \qquad i=1,\ldots,N_1.
\end{aligned}
$$

The <b>second hidden layer</b> is defined as:

$$
\begin{aligned}
\tilde a_i^{(2)} &= \sum_{j=1}^{N_1} W_{ij}^{(2)} a_j^{(1)} + b_i^{(2)}, \\
a_i^{(2)} &= \rho\left(\tilde a_i^{(2)}\right), \qquad i=1,\ldots,N_2.
\end{aligned}
$$

The output layer is defined as:

$$
y_i = \sum_{j=1}^{N_2} W_{ij}^{(3)} a_j^{(2)} + b_i^{(3)}.
$$

Once we've done so, we can formally define a <b>feedforward neural network</b> as a _"system"_ consisting of:
- weight matrices $W^{(1)} \in \mathbb{R}^{N_1 \times N_0}, \ldots, W^{(L)} \in \mathbb{R}^{N_L \times N_{L-1}}$
- biases $b_1 \in \mathbb{R}^{N_1}, \ldots, b_L \in \mathbb{R}^{N_L}$
- activation function $\rho: \mathbb{R} \to \mathbb{R}$

The realization of an FNN is the function $f_\theta: \mathbb{R}^{N_0} \to \mathbb{R}^{N_L}$ given by:

$$
f_\theta = f^{(L)} \circ \rho \circ f^{(L-1)} \circ \cdots \circ \rho \circ f^{(1)}.
$$

Here, the affine transformations $f^{(k)}: \mathbb{R}^{N_{k-1}} \to \mathbb{R}^{N_k}$ are defined by $f^{(k)}(x) = W^{(k)}x + b^{(k)}$.

Furthermore, we have that:

- $\rho(x_1,\ldots,x_{N_k}) := (\rho(x_1),\ldots,\rho(x_{N_k}))$
- $N_k$ is the <b>number of neurons</b> in the $k$-th layer, and $(N_0,\ldots,N_L) \in \mathbb{N}^{L+1}$ is the network's <b>architecture</b>
- $\theta = ((W^{(k)}, b^{(k)}), k = 1,\ldots,L)$ are the network <b>parameters</b>
- the <b>parameter space</b> is $\mathbb{R}^{P(N_0,\ldots,N_L)}$, where $P(N_0,\ldots,N_L) = \sum_{k=1}^{L} (N_k N_{k-1} + N_k)$

_Remarks:_ If the network outputs need to be in $\mathbb{R}_+$, $(0,1)$, or $(-1,1)$, we can add a final transformation $\phi$ on top of the last layer. If we do not specify one, we can assume $\phi = \mathrm{id}$.

_Another remark: a small recap of the terminology:_
- $k = 0$ is the <b>input layer</b>, $k = L$ is the <b>output layer</b>, and the others are the <b>hidden layers</b>
- $L + 1$ is the <b>number of layers</b>, and $L$ is the <b>depth</b>
- the network is said to be <b>shallow</b> if $L = 2$ _(only one hidden layer)_
- the network is said to be <b>deep</b> if $L \geq 3$
- $\|N\|_\infty = \max_k N_k$ is the <b>width</b> of the network

_Intuition: we can think of the network as a sequence of layers that transform the input:_ in the first layer, each neuron combines the inputs using weights, then adds a bias. Weights control how strongly each input matters; the bias shifts the result. Then, via the activation function, we apply $\rho$ to each neuron's result; this nonlinearity lets the network "learn" more than a simple linear relationship. <br/>For the next layers, we _"simply"_ repeat the same process, using the previous layer's activations as inputs.

Furthermore, we denote by $\mathcal{H}^\rho(N_0, N_1, \ldots, N_L)$ _(a vector space)_ the family of all FNNs with activation function $\rho$ and architecture $(N_0, N_1, \ldots, N_L)$.

_For example_, we can consider $\bigcup_{n \in \mathbb{N}} \mathcal{H}^\rho(d,n,1)$ as the class of all <b>shallow FNNs</b> with $d$-dimensional input and one-dimensional output. In this case, they can be represented by functions of the form:

$$
x \mapsto \sum_{i=1}^n W_{1i}^{(2)} \rho\left(\sum_{j=1}^d W_{ij}^{(1)} x_j + b_i^{(1)}\right) + b_1^{(2)}
$$

<b>Feedforward Neural Networks in Finance</b>

We now provide some examples of neural network applications in finance:
- <b>Option pricing</b>: learn the pricing function $(S/K, \tau, \sigma) \mapsto C/K$ for simulated or market option prices with a neural network, as shown in the 1994 paper by Hutchinson et al., <a href="https://doi.org/10.1111/j.1540-6261.1994.tb00081.x" target="_blank">A Nonparametric Approach to Pricing and Hedging Derivative Securities Via Learning Networks</a>.
- <b>Empirical asset pricing</b>: forecast excess returns $r_{i,t+1} = f_\theta(z_{i,t}) + \epsilon_{i,t+1}$ from firm characteristics $z_{i,t}$ _(size, value, momentum, etc.)_, as shown in the 2020 paper by Gu et al., <a href="https://doi.org/10.1093/rfs/hhaa009" target="_blank">Empirical Asset Pricing via Machine Learning</a>. _(In this case, we curiously see that networks with few hidden layers outperform linear models out of sample.)_
    - In particular, past research focused on the _"factor zoo"_ to determine returns, with scarce results, so Gu and Kelly treated this problem as a traditional prediction problem. <br/>They targeted 30,000 US stocks from 1957 to 2016, with roughly 94 features, and kept the training, validation, and testing data in chronological order _to avoid look-ahead bias._ Then, in their paper, they compared OLS, penalized linear models _(elastic net)_, PCR and PLS, generalized linear models with splines, random forests, and neural networks with 1 to 5 hidden layers, evaluating them on out-of-sample $R^2$.
    - Their biggest finding is that machine learning beats linear models out of sample and, _in particular,_ that shallow networks win, with performance peaking at about 3 hidden layers and then declining _(deeper networks overfit because the signal-to-noise ratio in returns is very low)_. The overperformance of neural networks comes from capturing nonlinearities and cross-interactions between features, which simple linear regression cannot represent. _Furthermore,_ they discovered that across all methods, the most important variables are momentum, liquidity, volatility, and size... _many other variables counted little!_
- <b>Deep hedging</b>: estimate the hedge ratio $\Delta_t = f_\theta(t, S_t, \Delta_{t-1})$ with a network, as in the 2019 Buehler paper, <a href="https://doi.org/10.1080/14697688.2019.1571683" target="_blank">Deep Hedging</a>.

<b>Universal Approximation Property</b>

The first proof of the UAP is credited to Cybenko in his 1989 paper. Four years later, Leshno et al. gave a necessary and sufficient condition on the activation function $\rho$ for the UAP to hold for shallow neural networks.

In particular, we can state the <b>UAP for shallow FNNs</b> as follows.

<b>Theorem 1 (UAP, Leshno et al., 1993)</b>

Let $K \subseteq \mathbb{R}^d$ be compact, and let $\rho: \mathbb{R} \to \mathbb{R}$ be a continuous activation function. The set $\bigcup_{n \in \mathbb{N}} \mathcal{H}^\rho(d,n,1)$ is dense in $C(K)$ with respect to the supremum norm if and only if $\rho$ is <b>not a polynomial</b>.

_Note that the UAP also holds for FNNs with a fixed number of hidden layers $k \geq 2$ _(if the width $N$ is allowed to go to $\infty$)_. Furthermore, the UAP also holds for FNNs with a fixed width $N \geq N_0 + N_L$ _(if the depth $L$ is allowed to go to $\infty$)_.

_Note also_ that in many applications FNNs provide a <b>more efficient approximation</b> than shallow FNNs.

_Intuition:_ consider neurons as the building blocks, so each neuron $\rho(Wx+b)$ is a _"ridge function"_ _(i.e., a step in one direction)_. Choosing $W$ and $b$ moves and orients the step, and $c$ scales it. <br/>If we sum many neurons, we can build any shape _(in 1D, this is analogous to approximating a function with steps)_.<br/>_However,_ if $\rho$ is a polynomial of degree at most $m$, the space of functions we can approximate is finite-dimensional. This implies that we need some _non-polynomial_ $\rho$ _(nonlinearity)_ to approximate complex shapes.

<b>How Neural Networks Learn</b>

We recall the <b>empirical loss minimization problem</b>: we want to solve:

$$
\inf_{f \in \mathcal{H}} \frac{1}{m}\sum_{i=1}^m \ell(f(x_i),y_i)
$$

for a training set $D$ of $m$ i.i.d. realizations of $(X,Y)$, a loss function $\ell: \mathbb{R} \times \mathbb{R} \to \mathbb{R}$, and a hypothesis class $\mathcal{H}$.

If we set $\mathcal{H} = \mathcal{H}^\rho(N_0,\ldots,N_L)$, we have:

$$
\begin{aligned}
\inf_{f_\theta \in \mathcal{H}^\rho(N_0,\ldots,N_L)} \frac{1}{m} \sum_{i=1}^m \ell(f_\theta(x_i),y_i)
&= \inf_{\theta \in \mathbb{R}^{P(N_0,\ldots,N_L)}} \frac{1}{m} \sum_{i=1}^m \ell(f_\theta(x_i),y_i).
\end{aligned}
$$

We can define $\mathcal{L}(\theta,D) = \frac{1}{m} \sum_{i=1}^m \ell(f_\theta(x_i),y_i)$.

We can now say that this <b>optimization problem</b> is _highly_ nontrivial:
- the parameter space $\mathbb{R}^{P(N_0,\ldots,N_L)}$ can be _very high-dimensional_
- if $\theta \mapsto \mathcal{L}(\theta,D)$ is almost everywhere differentiable, we can use (stochastic) gradient descent with $\theta_{t+1} = \theta_t - \eta_t \nabla_\theta \mathcal{L}(\theta_t,D)$
- _However,_ $\theta \mapsto \mathcal{L}(\theta,D)$ is typically <b>non-convex</b>; therefore, convergence to a global minimum is <b>not guaranteed</b>
- _Furthermore,_ computing $\nabla_\theta \mathcal{L}(\theta,D)$ is efficient even in large networks using <b>backpropagation</b>

_Also, note that_ during training, each network layer learns to produce features that are useful for the next layers to minimize the loss.


<b>Gradients and the Chain Rule</b>

We've seen that a neural network is a <b>computational graph</b>: the forward pass computes $a^{(0)} = x$, $a^{(1)}$, $a^{(2)}, \ldots, \hat y = \tilde a^{(L)}$, and the loss one layer after the other _(in the figure: black arrows)_. The backward pass computes the derivatives of the loss in the opposite order _(in the image: red arrows)_.

<div align = "center">
![Bias variance tradeoff](/images/notes/third-semester/chain-rule.png)
</div>

The <b>chain rule</b> then says that from one layer to the next one, the corresponding <b>Jacobian matrix</b>, with entries $\partial \tilde a_i^{(k+1)}/\partial \tilde a_j^{(k)}$, is:

$$
\frac{\partial \tilde a^{(k+1)}}{\partial \tilde a^{(k)}}
= W^{(k+1)}\operatorname{diag}\left(\rho'\left(\tilde a^{(k)}\right)\right)
\in \mathbb{R}^{N_{k+1}\times N_k}.
$$

_Therefore,_ the Jacobian over several layers is the product of these matrices:

$$
\frac{\partial \tilde a^{(3)}}{\partial \tilde a^{(1)}}
=
\frac{\partial \tilde a^{(3)}}{\partial \tilde a^{(2)}}
\frac{\partial \tilde a^{(2)}}{\partial \tilde a^{(1)}}.
$$

<b>Back propagation</b>

The main problem of training neural networks with gradient descent is that we have a loss function $\ell$ that depends on many parameters _(the weights $W$ and biases $b$ in every layer)_, so we would need $\partial \ell/\partial W_{ij}^{(k)}$ for all of them, which would be too expensive. To find an efficient solution, we first represent the network as a chain of functions and the loss as a nested composition.

For a data point $(x,y)$, let $a^{(0)}=x$, $\tilde a^{(k)}=W^{(k)}a^{(k-1)}+b^{(k)}$, and $a^{(k)}=\rho(\tilde a^{(k)})$ for $k<L$.

We define the <b>gradient</b> $\delta^{(k)} = \nabla_{\tilde a^{(k)}} \ell(\hat y,y) \in \mathbb{R}^{N_k}$, so we have:

- for the <b>output layer</b>: $\delta^{(L)} = \nabla_{\hat y}\ell(\hat y,y)$
- for the <b>hidden layers</b>:



$$
\delta_j^{(k)}
= \sum_{i=1}^{N_{k+1}}
\frac{\partial \ell}{\partial \tilde a_i^{(k+1)}}
\frac{\partial \tilde a_i^{(k+1)}}{\partial \tilde a_j^{(k)}}
= \sum_{i=1}^{N_{k+1}}
\delta_i^{(k+1)}W_{ij}^{(k+1)}
\rho'\left(\tilde a_j^{(k)}\right).
$$

That can be _nicely_ rewritten as:

$$
\delta^{(k)}
= \operatorname{diag}\left(\rho'\left(\tilde a^{(k)}\right)\right)
(W^{(k+1)})^T\delta^{(k+1)}.
$$


- for the <b>parameters</b>: since $\tilde a_i^{(k)} = \sum_{j=1}^{N_{k-1}} W_{ij}^{(k)}a_j^{(k-1)}+b_i^{(k)}$, we have:

$$
\frac{\partial \ell}{\partial W_{ij}^{(k)}}
= \delta_i^{(k)}a_j^{(k-1)},
\qquad
\frac{\partial \ell}{\partial b_i^{(k)}}
= \delta_i^{(k)},
$$

i.e.

$$
\nabla_{W^{(k)}}\ell
= \delta^{(k)}\left(a^{(k-1)}\right)^T,
\qquad
\nabla_{b^{(k)}}\ell
= \delta^{(k)}.
$$


_Notice that_ one forward pass (storing all $\tilde a^{(k)}$ and $a^{(k)}$) and one backward pass give all $P(N_0,\ldots,N_L)$ partial derivatives.

_Intuition:_ $\delta^{(k)}$ represents how much the loss cares about each neuron in layer $k$, or the error signal (blame) associated with each neuron:
- _for the output layer:_ the blame is easy to compute because $\delta^{(L)}$ is just the gradient of the loss with respect to the prediction;
- _for the hidden layers:_ a neuron $j$ in layer $k$ affects the loss only through the following neurons in layer $k+1$, so the blame is a sum over those neurons.

_So,_ with the backward pass, we can compute $\delta^{(L)}, \delta^{(L-1)}, \ldots$ in sequence, reusing each one for the next layer. Each $\delta$ also gives that layer's parameter gradients immediately.

<b>Gradient Descent and Mini-Batch Training</b>

We recall that with <b>gradient descent</b> (GD),

$$
\theta_{t+1}
= \theta_t - \eta_t \nabla_\theta \mathcal{L}(\theta_t,D),
$$

every step requires a pass over all $m$ data points, which can be too expensive for a large number of data points.

_(Also recall that $\mathcal{L}(\theta,D)$ is the loss averaged over the whole dataset $D$ of $m$ points: $\frac{1}{m}\sum_{i=1}^m \ell(\hat y_i,y_i)$.)_

We can now consider <b>mini-batch SGD</b>, which uses the average gradient over a random mini-batch of points. Let $B_t \subseteq \{1,\ldots,m\}$ with $|B_t|=n_{\mathrm{batch}}$:

$$
g_t
= \frac{1}{n_{\mathrm{batch}}}
\sum_{i\in B_t}
\nabla_\theta \ell\left(f_{\theta_t}(x_i),y_i\right),
\qquad
\mathbb{E}[g_t\mid\theta_t]
= \nabla_\theta \mathcal{L}(\theta_t,D),
\qquad
\operatorname{Cov}(g_t\mid\theta_t)
= O\left(\frac{1}{n_{\mathrm{batch}}}\right).
$$

We clearly see that the mini-batch gradient is a <b>noisy but unbiased</b> estimate of the full gradient, i.e. the noise level _(the variance of the estimate)_ scales like $1/n_{\mathrm{batch}}$. A bigger batch gives a more accurate direction but costs more.

_Note also that_ $n_{\mathrm{batch}}$ _(batch size)_ should be treated as a <b>hyperparameter</b> and tuned accordingly.

Therefore, the <b>mini-batch stochastic gradient descent</b> algorithm can be simplified as follows:

```python
t = 0
for epoch in range(E):
    perm = random_permutation(m)
    for start in range(0, m, n_batch):
        idx = perm[start:start + n_batch]
        loss = mean(loss_fn(model(X[idx], theta), y[idx]))
        g = backprop(loss, theta)        # ∇_θ loss
        theta = theta - eta[t] * g
        t += 1
```

<b>The Learning Rate</b>

We first recall that the <b>Hessian</b> is the matrix of second-order partial derivatives of a scalar function. For a loss $\mathcal{L}(\theta)$, its entries are:

$$
H_{ij}(\theta) = \frac{\partial^2 \mathcal{L}(\theta)}{\partial \theta_i \,\partial \theta_j}.
$$

It describes how the loss curves in different parameter directions: _near a minimum,_ it helps approximate the loss and understand how quickly optimization converges.

The <b>learning rate</b> (step size) $\eta$ is usually the most important hyperparameter.

If we consider a <b>quadratic model</b>, we clearly see that near a minimum $\theta^*$ we have that:

$$
\mathcal{L}(\theta) \approx \mathcal{L}(\theta^*) + \frac{1}{2}(\theta - \theta^*)^T H(\theta - \theta^*)
$$

with Hessian $H \succ 0$ with eigenvalues $0 < \lambda_{\min} \leq \cdots \leq \lambda_{\max}$.

In this case, the gradient descent satisfies:

$$
\theta_{t+1} - \theta^* = (I - \eta H)(\theta_t - \theta^*)
$$

which implies

$$
\|\theta_t - \theta^*\|_2 \leq \left(\max_i |1 - \eta \lambda_i|\right)^t \|\theta_0 - \theta^*\|_2.
$$

so gradient descent converges if and only if $0 < \eta < 2/\lambda_{\max}$.



_Furthermore,_ we can see that the <b>best constant step size</b> _(i.e. the best learning rate)_ is $\eta = 2/(\lambda_{\min} + \lambda_{\max})$, which gives the <b>rate</b> _(i.e. the factor by which we reduce the error per step)_ equal to
$$
\max_i |1 - \eta \lambda_i| = \frac{\kappa - 1}{\kappa + 1},
$$
where $\kappa = \lambda_{\max}/\lambda_{\min}$ is the condition number.


<div align = "center">
![Bias variance tradeoff](/images/notes/third-semester/learning-rate.png)
</div>

_However, notice that_ with mini-batch gradients and a constant $\eta$, SGD eventually stops converging: the iterates keep fluctuating around $\theta^*$ in a region that grows with $\eta$ and with the gradient noise.

_Furthermore,_ the <b>Robbins-Monro conditions</b> give that
$$
\sum_{t=0}^\infty \eta_t = \infty,
\qquad
\sum_{t=0}^\infty \eta_t^2 < \infty.
$$


SGD converges _(i.e. for strongly convex objectives with bounded gradient noise, we have convergence)_.

In practice, below are some learning rates often used in practice:
- <b>step decay</b>: $\eta_t = \eta_0 \gamma^{\lfloor t/T \rfloor}$ _(i.e. $\gamma = 0.1$ every $T$ steps)_
- <b>cosine annealing</b>: $\eta_t = \eta_{\min} + \frac{1}{2}(\eta_0 - \eta_{\min})(1 + \cos(\pi t/T))$, $0 \leq t \leq T$
- <b>learning rate reduction on plateaus</b>: halve $\eta$ when the validation loss has not improved for some epochs
- <b>warm-up learning rate</b>: increase $\eta$ linearly during the first iterations
- <b>rule-of-thumb learning rate</b>: choose $\eta$ on a logarithmic grid _(e.g. $10^{-4}, 10^{-3}, \ldots, 10^{-1}$)_ and take the largest value that does not diverge, then reduce it.

<b>Hyperparameters and Model Selection</b>

Hyperparameters _(such as architecture (depth $L$, widths $N_k$, activation $\rho$), learning rate, batch size, number of epochs, and regularization ($\lambda$, dropout rate $q$), etc.)_ are <b>not learned in SGD</b>.

Instead, they are usually chosen by minimizing the error on a _validation set,_ distinct from the training and test sets.

For financial data, we usually do NOT shuffle across time to avoid <b>look-ahead bias</b>: instead, we usually use a <b>walk-forward split</b> _(via an expanding or rolling window)_ and use the test set only once, at the very end.

<b>Optimizers: Momentum and RMSProp</b>

Consider $g_t$, the mini-batch gradient at $\theta_t$, and note that squares, square roots, and divisions of vectors are taken _component-wise_. We now spend some time mentioning some optimizer techniques.

<b>Momentum (heavy ball optimizer), from <a href="https://link.springer.com/article/10.1007/BF00900876" target="_blank">Polyak, 1964</a></b>


The idea is to accumulate an _exponentially weighted_ velocity, given $\beta \in [0,1]$, typically $\beta = 0.9$:

$$
v_{t+1} = \beta v_t + g_t, \qquad \theta_{t+1} = \theta_t - \eta v_{t+1}.
$$

In the case $v_0 = 0$, we have that
$$
v_{t+1} = \sum_{s=0}^t \beta^{t-s}g_s
$$
is an _exponentially weighted_ sum of past gradients that is able to <b>average out</b> part of the mini-batch noise.

In this case, consistent gradients add up: if $g_s = g$ for all $s$, then
$$
v_{t+1} = (1 + \beta + \beta^2 + \cdots + \beta^t)g \to \frac{g}{1-\beta},
$$
so the effective step size is $\eta/(1-\beta)$, which is $10\eta$ when $\beta = 0.9$.

_Furthermore,_ gradients that change sign cancel out: if $g_s = (-1)^s g$, then
$$
v_{t+1} = \sum_{s=0}^t \beta^{t-s}(-1)^s g \to \pm\frac{g}{1+\beta},
$$
so the step size reduces to $\eta/(1 + \beta)$, which is approximately $\eta/2$ when $\beta = 0.9$.

<b>RMSProp (Root Mean Square Propagation)</b>

For this optimizer, we consider a specific <b>per-coordinate step size</b> from a running average of squared gradients. _Formally,_ if we set $\beta_2 \approx 0.00$ and $\epsilon \approx 10^{-9}$, we can write:

$$
s_{t+1} = \beta_2 s_t + (1 - \beta_2)g_t^2, \qquad
\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{s_{t+1}} + \epsilon}g_t.
$$

_In this case,_ coordinates with large (small) gradients get small (large) steps; the update is (almost) invariant to rescaling individual parameters, which helps with badly scaled problems.

<b>Adam Optimizer, from <a href="https://arxiv.org/abs/1412.6980" target="_blank">Kingma and Ba, 2015</a></b>

The idea behind this is that it combines momentum, RMSProp, and bias correction in a single optimizer: we consider a momentum step $\hat m_t$ divided in each coordinate by the typical size of the gradients in that coordinate, $\sqrt{\hat s_t}$. To understand it better, we start from the algorithm in pseudocode:

```python

eta = 1e-3
beta1 = 0.9
beta2 = 0.999
epsilon = 1e-8

theta = theta0
m = 0
s = 0

for t in range(1, num_iterations + 1):
    # Mini-batch gradient at theta
    g = backpropagation_gradient(theta)

    m = beta1 * m + (1 - beta1) * g
    s = beta2 * s + (1 - beta2) * (g ** 2)

    m_hat = m / (1 - beta1**t)
    s_hat = s / (1 - beta2**t)

    theta = theta - eta * m_hat / (s_hat**0.5 + epsilon)

```

_Formally,_ we can see this and the bias correction by unrolling the recursion and starting with $m_0 = 0$:

$$
m_t = (1 - \beta_1)\sum_{s=1}^t \beta_1^{t-s}g_s.
$$

The weights sum to
$$
(1 - \beta_1)\sum_{s=1}^t \beta_1^{t-s} = 1 - \beta_1^t < 1.
$$

_So,_ $m_t$ is a weighted sum of $g_1,\ldots,g_t$ whose weights sum to less than one.

If $\mathbb{E}[g_s] = g$ for all $s$, then $\mathbb{E}[m_t] = (1-\beta_1^t)g$. For example, $m_1 = 0.1g_1$; dividing by $1-\beta_1^t$ gives $\mathbb{E}[\hat m_t] = g$.

_Note that_ the same holds for $s_t$ with the factor $1 - \beta_2^t$, which stays far below 1 for much longer ($\beta_2 = 0.999$).

To understand the step size, note that, in each coordinate, $\hat m_t$ estimates $\mathbb{E}[g]$ and $\hat s_t$ estimates $\mathbb{E}[g^2]$. By Jensen's inequality, $|\mathbb{E}[g]| \leq \sqrt{\mathbb{E}[g^2]}$, so the Adam step is at most about $\eta$ in magnitude in each coordinate, and is smaller when gradients are noisy (i.e. change sign).

Multiplying the loss by $c > 0$ multiplies $g_t$ and $\hat m_t$ by $c$ and $\hat s_t$ by $c^2$, so the Adam step does not change (up to $\epsilon$), whereas the SGD step $\eta g_t$ is multiplied by $c$.

Therefore, $\eta$ is roughly the largest change of each parameter per step, so the same $\eta$ (e.g. $10^{-3}$) works for very different problems; this is why Adam is the usual default.

<div align = "center">
![Bias variance tradeoff](/images/notes/third-semester/learning-rate-3.png)
</div>

_As we can see from the picture above,_ on an ill-conditioned quadratic (with $\kappa = 100$), GD with its optimal constant step size zigzags across the valley and converges slowly, while momentum and Adam optimizers converge much faster.

_On the other hand,_ on quadratics, momentum with specified parameters improves the rate _(error reduction factor per step)_ of GD from $\frac{\kappa - 1}{\kappa + 1}$ to $\frac{\sqrt{\kappa} - 1}{\sqrt{\kappa} + 1}$.

_However,_ note that no optimizer is best for every problem: SGD with momentum is often used for CNNs, while Adam or a variant of Adam _(AdamW)_ is used for transformers _(and, again, recall that the learning rate must be tuned in any case)_.

<b>Practical Training Issues: Standardization</b>

Often, standardizing each input feature using the mean and standard deviation _over the training set_ improves performance:

$$
\tilde{x}_{ij} = \frac{x_{ij} - \hat{\mu}_j}{\hat{\sigma}_j},
\qquad
\hat{\mu}_j = \frac{1}{m}\sum_{i=1}^{m} x_{ij},
\qquad
\hat{\sigma}_j^2 = \frac{1}{m}\sum_{i=1}^{m}(x_{ij} - \hat{\mu}_j)^2.
$$

Apply the same $(\hat{\mu}_j, \hat{\sigma}_j)$ to validation and test data (alternatively, use min-max scaling to $[0,1]$).

This works because, for linear least squares, the Hessian is $H = \frac{2}{m}X^\top X$. Features on very different scales make $\kappa$ large and gradient descent extremely slow. For example, moneyness $S/K \approx 1$ may appear alongside days to maturity $\approx 10^2$ in option datasets.

Least squares on (moneyness, days to maturity), with 50 gradient descent steps and $\eta = 1/\lambda_{\max}$:
- Raw inputs: gradient descent quickly reaches the valley floor (the steep direction is approximately $w_2$, the weight of days to maturity), then barely moves toward the minimum $\star$.
- Standardized inputs: $\kappa \approx 1.1$, and gradient descent reaches the minimum $\star$.

<div align = "center">
![Bias variance tradeoff](/images/notes/third-semester/learning-rate-4.png)
</div>

<b>Standardization in Finance</b>

Targets: scale them too, so that they are of order 1, like the output of the network at initialization. Otherwise, the loss and its gradient (e.g. $2(\hat{y} - y)$ for the squared loss) are dominated by the largest targets, and a learning rate that works for one scale fails for another.

Example: option prices. Use $C/K$ instead of $C$. If the price is homogeneous of degree one in $(S,K)$, i.e. $C(\lambda S, \lambda K, \tau) = \lambda C(S,K,\tau)$ for all $\lambda > 0$ (e.g. in the Black-Scholes model), then setting $\lambda = 1/K$ gives

$$
\frac{C(S,K,\tau)}{K} = C\left(\frac{S}{K},1,\tau\right) \in [0,S/K].
$$

So the target is of order 1, and the network needs one fewer input (moneyness $S/K$ instead of $S$ and $K$) (<a href="https://doi.org/10.1111/j.1540-6261.1994.tb00081.x" target="_blank">Hutchinson et al., 1994</a>).

Time series: compute $\hat{\mu}_j$ and $\hat{\sigma}_j$ using past data only (e.g. on rolling windows). Statistics computed on the full sample contain information from the test period.

Heavy tails: returns, volumes, and spreads have heavy tails. A few extreme values inflate $\hat{\sigma}_j$ and dominate the loss, so winsorize (clip at, e.g., the 1% and 99% quantiles of the training set) or use log transforms.

<b>Initialization</b>

_In general,_ the critical point reached by SGD depends on the initialization $\theta_0$, because the loss function is not convex in $\theta$.

If we initialize all parameters to a common constant $c$, i.e. set $\theta_0 = c$, then all neurons in a layer compute the same output (e.g. $\tilde{a}_i^{(1)} = c\sum_j x_j + c$ for all $i$) and receive the same gradients (in backpropagation, $\delta_i^{(k)}$ is the same for all $i$). Therefore, they stay identical during training, and the layer effectively has a single neuron. We must initialize the neurons differently, e.g. randomly.

We can use random initialization, but if $\theta_0$ is too small:
- gradients vanish (in the chain rule, we multiply weights that are on average smaller than one)

If $\theta_0$ is too big:
- gradients explode (in the chain rule, we multiply weights that are on average larger than one).

An initializer that works well is the Xavier (Glorot) initialization [Glorot and Bengio, 2010]:

$$
W_{ij}^{(k)} \overset{\mathrm{iid}}{\sim} \mathcal{N}\left(0, \frac{2}{N_{k-1}+N_k}\right),
\qquad b^{(k)} = 0, \quad 1 \leq k \leq L,
$$

where $N_{k-1}$ and $N_k$ are the widths of layers $k-1$ and $k$.

Why? With independent centered weights and $b^{(k)} = 0$, $\tilde{a}_i^{(k)} = \sum_{j=1}^{N_{k-1}} W_{ij}^{(k)}a_j^{(k-1)}$ has variance

$$
\operatorname{Var}(\tilde{a}_i^{(k)}) = \sum_{j=1}^{N_{k-1}} \operatorname{Var}(W_{ij}^{(k)})\,\mathbb{E}\left[(a_j^{(k-1)})^2\right].
$$

If $\rho(x) \approx x$ near 0 (e.g. $\rho(x) = \tanh(x)$), then $\mathbb{E}[(a_j^{(k-1)})^2] \approx \operatorname{Var}(\tilde{a}_j^{(k-1)})$. Thus, the variance neither vanishes nor explodes across layers if $\operatorname{Var}(W_{ij}^{(k)}) = 1/N_{k-1}$. The same argument for the backward pass (a sum over the $N_k$ neurons of layer $k$) gives $1/N_k$; Xavier takes a compromise between the two.

ReLU sets about half of the pre-activations to 0, so $\mathbb{E}[(a_j^{(k)})^2] \approx \frac{1}{2}\operatorname{Var}(\tilde{a}_j^{(k)})$. He initialization, $W_{ij}^{(k)} \overset{\mathrm{iid}}{\sim} \mathcal{N}(0,2/N_{k-1})$ [He et al., 2015], compensates with the factor 2.

Other initializers can also be used (see, e.g., `torch.nn.init` and `tf.keras.initializers`). Typically, one repeats the training for different sampled values of $\theta_0$.
---
<br/>
<b>Batch Normalization</b>

Problem: during training, parameter updates in one hidden layer often shift or rescale the input of the next hidden layer, which slows down training (internal covariate shift).

Main idea: stabilize training by normalizing the activations of each hidden layer using the empirical mean and standard deviation over each batch.

If $(x_i)_{i=1}^{n_{\mathrm{batch}}}$ is a batch of size $n_{\mathrm{batch}}$ and $a_j^{(k)}$ is the activation of the $j$-th neuron in the $k$-th layer, then:

$$
a_j^{(k)}(x_i) \leftarrow \frac{a_j^{(k)}(x_i)-\mu_j^{(k)}}{\sqrt{\sigma_j^{2(k)}+\epsilon}},
$$

where

$$
\mu_j^{(k)} = \frac{1}{n_{\mathrm{batch}}}\sum_{i=1}^{n_{\mathrm{batch}}}a_j^{(k)}(x_i),
\qquad
\sigma_j^{2(k)} = \frac{1}{n_{\mathrm{batch}}}\sum_{i=1}^{n_{\mathrm{batch}}}\left(a_j^{(k)}(x_i)-\mu_j^{(k)}\right)^2,
$$

and $\epsilon > 0$ is a small constant ($\epsilon \approx 10^{-5}$) to prevent division by zero.

_Note that_ normalized activations are usually then rescaled, $a_j^{(k)} \leftarrow \gamma_j^{(k)}a_j^{(k)} + \beta_j^{(k)}$, with learnable parameters $\gamma_j^{(k)}$ and $\beta_j^{(k)}$, so the layer can undo the normalization if useful. At test time, $\mu_j^{(k)}$ and $\sigma_j^{2(k)}$ are replaced by averages from training.

_Practically speaking,_ in PyTorch and TensorFlow, batch normalization is implemented as a layer (see `torch.nn.BatchNorm2d` and `tf.keras.layers.BatchNormalization`).
---
<br/>
<b>Regularization</b>

Loss functions are typically regularized, i.e., we prefer to minimize a <b>modified objective</b> constructed from the hyperparameter $\lambda$:

$$
\tilde{\mathcal{L}}(\theta, D) = \mathcal{L}(\theta, D) + \lambda \mathcal{R}(\theta)
$$

Popular choices of $\mathcal{R}(\theta)$ are:
- $\mathcal{R}(\theta) = \|\theta\|_2^2$, which shrinks $\theta$ in directions that do not minimize the objective enough
- $\mathcal{R}(\theta) = \|\theta\|_1$, which encourages a sparse $\theta$

_Note, of course,_ that we only regularize the weights $W$ and do not touch the biases in order to avoid underfitting, and that different regularization parameters $\lambda$ can be applied to different layers.

In particular, we can now consider <b>weight decay</b>, which shrinks parameters toward 0 at every step by setting:

$$
\theta_{t+1} = (1 - \eta\lambda)\theta_t - \eta g_t.
$$

_Note that,_ for stochastic gradient descent, this translates to $L^2$ regularization: the gradient of $\mathcal{L}(\theta,D) + \frac{\lambda}{2}\|\theta\|_2^2$ is $g_t + \lambda\theta_t$, so $\theta_{t+1} = \theta_t - \eta(g_t + \lambda\theta_t) = (1 - \eta\lambda)\theta_t - \eta g_t$.


_Instead,_ for adaptive methods, weight decay and $L^2$ regularization are <b>not equivalent</b>: with Adam, for example, the $L^2$ term $\lambda\theta_t$ is divided by $\sqrt{\hat s_t}$, implying that parameters with large gradients are regularized less.

_Secondly,_ note that <b>training techniques</b> can be regularizers too. _For example,_ consider:
- <b>early stopping</b>: for a fixed $p \in \mathbb{N}$ (<b>patience parameter</b>), we stop training if, after $p$ steps, the error on a _validation set_ has not decreased, and we go back to the parameters with the minimum validation error. _(Note that this can equivalently be seen as choosing the number of SGD steps based on a validation set.)_
- <b>dropout</b>: before each gradient step, we set each neuron to zero with probability $q$ _(independently of all others)_, then perform backpropagation as usual. This encourages sparse and redundant representations _(this can be viewed equivalently as training exponentially many neural networks)_.


To see this in practice, we now present a dropout method, proposed by Srivastava et al. in 2014, in the <b>inverted form</b>: during training, we multiply the activations of each hidden layer by a random mask, _that is:_1

$$
a^{(k)} \leftarrow \frac{1}{1-q}\,\xi^{(k)} \odot a^{(k)},
\qquad
\xi_j^{(k)} \overset{\mathrm{iid}}{\sim} \operatorname{Ber}(1-q).
$$

so that the expected activation is unchanged and no dropout is applied at test time. _(Note that $\odot$ is element-wise (Hadamard) multiplication.)_

<b>Choosing Evaluation Metrics</b>

We first recall that the training loss is chosen for optimization such that it is cheap to compute and differentiable. Choosing the <b>evaluation metric</b> is _another story_ and should reflect how the model will be used and, _more importantly,_ it is computed on the test set. We now present some evaluation metrics.

- For <b>regression</b>, we can often use:
    - MSE: $\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2$
    - RMSE: $\sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2}$
    - MAE: $\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat y_i|$
    - $R^2_{\mathrm{oos}}=1-\frac{\sum_{t=1}^{T}(r_t-\hat r_t)^2}{\sum_{t=1}^{T}(r_t-\hat r_{t,\mathrm{bench}})^2}$ _(for return forecasts, where $\hat r_{t,\mathrm{bench}}$ is the benchmark forecast)_

- For <b>classification</b>, we prefer methods that look for accuracy and precision (<b>F1, ROC and AUC</b>; <a href="#classification-metrics">click here to review them</a>). For predicted probabilities, we can use the <b>log-loss</b>: $-\frac{1}{n}\sum_{i=1}^{n}\left[y_i\log(\hat p_i)+(1-y_i)\log(1-\hat p_i)\right]$, or the <b>Brier score</b>: $\frac{1}{n}\sum_{i=1}^{n}(\hat p_i-y_i)^2$.
- For <b>finance-specific topics</b>, we consider pricing errors in implied-volatility points rather than in prices, hedging errors and, _for training signals or strategies,_ we can consider P&L, Sharpe Ratio, turnover and drawdowns of the optimized strategy, _better after transaction costs_.

_Lastly,_ always compare with simple benchmarks (historical mean, linear regression, GARCH, Black–Scholes, etc.) and evaluate over several periods and market regimes.

<b>Little off-topic on implementation: tensors and automatic differentiation in PyTorch</b>

We recall that a tensor is an n-dimensional array on a CPU/GPU.

Operations on tensors with `requires_grad=True` are recorded in a computational graph; `backward()` then runs reverse-mode automatic differentiation (backpropagation):

We can consider the following example, where we try to compute a portfolio's variance and then estimate variance changes depending on weights using `backward()`.

`backward()` starts from the variance, and PyTorch walks the graph backward and applies the chain rule at each node. This is reverse-mode automatic differentiation, and it is the same algorithm as backpropagation in neural networks. The result is exact. It is not a numerical approximation like $(f(w+\varepsilon)-f(w))/\varepsilon$.

```python
import torch
Sigma = torch.tensor([[0.04, 0.006],
                      [0.006, 0.09]])           # covariance matrix of two assets
w = torch.tensor([0.6, 0.4], requires_grad=True)   # portfolio weights
variance = w @ Sigma @ w
variance.backward()
print(variance.item(), w.grad)
# portfolio variance w' Sigma w
# reverse-mode automatic differentiation
# 0.03168  tensor([0.0528, 0.0792])
```

Note that automatic differentiation is exact up to floating-point errors _(no finite-difference error)_.

To find the best parameter, we apply the following logic:
- run an initial broad grid
- _once a grid is done,_ inspect that grid and the selected parameter
- if the parameter is at or near the border, expand that side and re-run
- stop only when the selected values are inside the final grid _(we do not automatically stop at the first grid if the optimum parameter looks constrained by the chosen grid, in order to not introduce selection/prior bias)_
<br/>
```python
searches, rows = {}, []
for name, (pipeline, grid) in models.items():
    search = GridSearchCV(pipeline, grid, scoring="neg_mean_squared_error", cv=cv, refit=True, n_jobs=1)
    search.fit(X_train_raw, y_train)
    searches[name] = search
    i = search.best_index_
    train_mse, train_r2, test_mse, test_r2 = evaluate(search.best_estimator_, X_train_raw, X_test_raw)
    rows.append([name, search.best_params_, -search.cv_results_["mean_test_score"][i], search.cv_results_["std_test_score"][i],
                 train_mse, train_r2, test_mse, test_r2])
    # At or near the boundary = one of the two lowest or two highest grid values.
    boundary = [key for key, values in grid.items() if search.best_params_[key] in [*sorted(values)[:2], *sorted(values)[-2:]]]
    print(f"{name}: {'extend and rerun ' + str(boundary) if boundary else 'selected values are not at or near the edge of the final grid.'}")
```

## <a id="p2"><b>P2 Credit Analytics  </b></a>

Before starting with the practical coding project, we give a short introduction of the topic.

In every day language, we often associate risk \approx uncertainty. _However,_ risk management is more precise, since it defines risk as the exposure to the possibility of loss.

For the sake of this project, we define <b>credit risk</b> as the risk coming from losses from borrowers who default. Therefore, _later in the code,_ we will model each borrower $i$ with a default probability $1 - p(x_i)$, where $p(x_i)$ is the probability the borrower repays.

We can then consider three different ways to represent risk, for a random loss $L$:
- <b>Variance</b>: $\operatorname{Var}(L)=\mathbb{E}\left[(L-\mathbb{E}[L])^2\right]$
- <b>Value at Risk (VaR)</b> at confidence level $\alpha$ (usually $\alpha=0.95$): $\operatorname{VaR}_{\alpha}(L)=\inf\{\ell\in\mathbb{R}:\mathbb{P}(L\leq\ell)\geq\alpha\}$. At 95%, this is the loss threshold exceeded in the worst 5% of outcomes.
- <b>Expected Shortfall (ES)</b> at confidence level $\alpha$: $\operatorname{ES}_{\alpha}(L)=\frac{1}{1-\alpha}\int_{\alpha}^{1}\operatorname{VaR}_{u}(L)\,du$. This is the average loss in the worst $1-\alpha$ fraction of outcomes.

VaR is simpler and widely used, but... ES is getting more and more popular because it looks into the tail.

There are two main common methods to assess risk:
- <b>Monte Carlo scenarios</b>, where we simulate many outcomes _(in this way, we ask the question "who repays?" multiple times)_ and, _for each scenario,_ compute the corresponding P&L so we can understand how bad and how often it happens, _given that the model is right_.
- <b>Stress scenario</b>, where we choose a specific adverse situation and compute P&L in that specific situation, without knowing how likely this bad scenario is.

_To sum up..._ in the following project, we model each borrower with a repayment probability and, given specified lending decisions, simulate different scenarios to compute the portfolio P&L distribution and then its expected P&L and VaR.

_Note that_ using standardized data (i.e., $\hat{x} = \frac{x - \mu}{\sigma}$) instead of normalized data would not change the results.

In particular, we can show that, for two observations $i$ and $l$, with $\hat{\mu}_j$ and $\hat{\sigma}_j$, we have:

$$
\tilde{z}_{ij}-\tilde{z}_{lj}
=
\frac{x_{ij}-\hat{\mu}_j}{\hat{\sigma}_j}
-
\frac{x_{lj}-\hat{\mu}_j}{\hat{\sigma}_j}
=
\frac{x_{ij}}{\hat{\sigma}_j}
-
\frac{x_{lj}}{\hat{\sigma}_j}
=
\tilde{x}_{ij}-\tilde{x}_{lj}.
$$


So we have that:


$$
k(\tilde{z}_i,\tilde{z}_l)
=
\exp\left(
-\frac{1}{10}\sum_{j=1}^{3}(\tilde{z}_{ij}-\tilde{z}_{lj})^2
\right)
=
\exp\left(
-\frac{1}{10}\sum_{j=1}^{3}(\tilde{x}_{ij}-\tilde{x}_{lj})^2
\right)
=
k(\tilde{x}_i,\tilde{x}_l).
$$

Then the SVC fit depends on the data _only through_ these kernels, so the dual coefficients $a^*$ and the intercept $b$ are identical:


$$
\hat{f}^{\mathrm{svm}}_s(\tilde{z})
=
\sum_{i=1}^{m}a_i^*y_i\,k(\tilde{z}_i,\tilde{z})+b
=
\sum_{i=1}^{m}a_i^*y_i\,k(\tilde{x}_i,\tilde{x})+b
=
\hat{f}^{\mathrm{svm}}_s(\tilde{x}).
$$
